- **结构体 / 枚举 / Trait**：`PascalCase`（与 Java 一致）

- **模块 / 文件名**：`snake_case`（与 Java `lowercase` 不同）

## 十一、命名约定（重申）

- **结构体 / 枚举 / Trait**：`PascalCase`（与 Java 一致）
- **方法 / 函数**：`snake_case`
- **模块 / 文件名**：`snake_case`
- **常量**：`SCREAMING_SNAKE_CASE`
- **特征 trait**：以 `able` 结尾（如 `Readable`）或 `Handler` / `Setter` /
  `Editor` 等名词
- **抽象 trait**：以 `AbstractXxx` 前缀，对齐 Java 命名

> 示例（来自实际文件）：
> - `BigExcelWriter` → `pub struct BigExcelWriter`
> - `ExcelUtil::getWriter` → `pub fn get_writer(...)`
> - `WorkbookFactory` → `pub struct WorkbookFactory`
> - `AbstractSheetReader` → `pub struct AbstractSheetReader`
> - `BeanSheetReader<T>` → `pub struct BeanSheetReader<T>`
