## 一、总目标

以 Hutool 5.8.x `hutool-cron` 模块（`cn.hutool.cron.*` 共 **34 个 Java 类**）为蓝本，
实现功能语义完全对齐的 `hutool-cron` crate。**目标 34 个 Java 类 → 34 个独立 Rust 文件**
（禁止合并到 `compat.rs`）。

### 设计原则

1. **功能语义对齐，实现方式 Rust 化**：
   - `java.util.Timer` + `TimerTask` → `tokio::time::sleep` + `JoinHandle`
   - `java.util.concurrent.ScheduledExecutorService` → `tokio::task`
   - `java.time.LocalDateTime` → `chrono::Local`
   - `TimeUnit` → `std::time::Duration`
   - `cron` 表达式解析 → `cron` crate
   - 时间轮（TimingWheel）→ 自实现
2. **每个 .rs 文件只对应一个 Java 对象**：禁止把多个 Java 类合并到 `compat.rs`。
3. **保留所有已有迁移内容**：hutool-cron 当前 20 个 Rust 文件（pattern 子包 11 + timingwheel 子包 4 + lib/compat 2 + tests/...），
   顺原思路继续，不得删减。
4. **公开类型必须有中文文档注释**：结构体、trait、方法、字段。
5. **依赖 `hutool-core`**：复用 `date/`、`lang/` 等基础设施。
6. **测试覆盖**：cron 表达式解析、调度器启停、任务触发各 1+ 测试。
