# hutool-cron → hutool-cron 功能语义迁移对照表

基线：Hutool **5.8.x** `hutool-cron`（`cn.hutool.cron.*` 34 个类）。
迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 的 `java.util.Timer` + `TimerTask` 映射为 `tokio::time::sleep` + `JoinHandle`；
`ScheduledExecutorService` 映射为 `tokio::task`；
`java.time.LocalDateTime` 映射为 `chrono::Local`；
时间轮（TimingWheel）自实现。

状态图例：✅ 已迁移并有测试 / 🔶 语义等价但形态不同 / ⬜ 未迁移（路线图）/ 🚫 不迁移 / 🆕 Rust 特有

## ⚠️ 重要违规提示

## 十一、cron 表达式格式

```
秒 分 时 日 月 周 [年]
*  *  *  *  *  ?  *
```

- 7 段（含年）或 6 段（不含年）
- 特殊字符：`*` `,` `-` `/` `?` `L` `W` `#`
- Hutool cron 解析复用 `cron` crate，扩展了年字段
