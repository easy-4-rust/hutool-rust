| 领域 | Java 合同 | Rust 机制起点 | 统一验收 |

| 错误 | 异常类别、cause、部分副作用 | typed `Result` + `thiserror` | 类别、source、重试/回滚、脱敏 |

| 并发/I-O | 锁、线程、本地变量、流与资源 | ownership、Arc/锁/channel/Tokio、RAII | 原子性、取消、背压、关闭、泄漏 |

| 组件 | Java 外部组件 | std/direct crate/adapter/host | 硬门禁、POC、共享合同、host、回滚 |
