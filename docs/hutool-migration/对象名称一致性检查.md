## 三、命名规范的强约束（必须遵守）

1. **类型 PascalCase**：`StrUtil`, `FileUtil`, `BeanHandler`, `CacheListener`
2. **方法 snake_case**：`is_blank`, `read_lines`, `write_to_file`, `new_with_capacity`
3. **模块 snake_case**：`util`, `io`, `text`, `cache_listener`, `user_agent`
4. **文件 snake_case**：每个 `.rs` 文件名严格 snake_case 且对应一个 Java 类
5. **常量 UPPER_SNAKE_CASE**：`DEFAULT_BUFFER_SIZE`, `MAX_READER_BYTES`
6. **生命周期参数小写**：`'a`, `'de`, `'static`
7. **泛型参数 PascalCase**：`T`, `K`, `V`, `E`, `Item`
8. **Trait 方法 snake_case**（不用 get_xxx 前缀，Rust 习惯直接 `xxx()`）
9. **错误类型 `XxxError`** 后缀（如 `BooleanError`, `CharError`）
10. **结果类型 `Result<T, XxxError>`** 而非 `Result<T>` 别名
