> 检查时间：2026-07-27
> 基线：Hutool 5.8.x `cn.hutool.extra.*`（128 个 Java 类，16 个子包）

| 维度 | Hutool | hutool-extra | 说明 |
|------|--------|--------------|------|
| Java 类总数 | 128 | — | 排除 `package-info` |

## 五、命名风格检查

| 检查项 | Java | Rust | 结论 |
|--------|------|------|------|
| 类型命名 | `PascalCase` | `PascalCase` | ✅ 一致 |
| 方法命名 | `camelCase` | `snake_case` | ✅ 符合 Rust 惯例 |
| 字段命名 | `camelCase` | `snake_case` | ✅ 符合 Rust 惯例 |
| 常量命名 | `UPPER_SNAKE_CASE` | `UPPER_SNAKE_CASE` | ✅ 一致 |
| 文件名 | `PascalCase.java` | `snake_case.rs` | ✅ 符合 Rust 惯例 |
| 目录名 | 小写单词 | `snake_case` | ✅ 一致 |
| 抽象前缀 | `Abstract*` | `Abstract*` | ✅ 一致（如 `AbstractTemplate`、`AbstractFtp`） |
| 异常后缀 | `*Exception` | `*Exception` | ✅ 一致 |
| 工具后缀 | `*Util` | `*Util` | ✅ 一致 |
| 引擎后缀 | `*Engine` | `*Engine` | ✅ 一致 |
| 工厂后缀 | `*Factory` | `*Factory` | ✅ 一致 |
| Util 命名冲突 | — | — | ⚠️ `MailUtil`/`CompressUtil` 跨越两个 crate，依赖 `use` 别名区分 |
