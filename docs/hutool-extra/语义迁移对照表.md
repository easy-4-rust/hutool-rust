# hutool-extra 功能语义迁移对照表

> 检查时间：2026-07-27
> 基线：Hutool 5.8.x `cn.hutool.extra.*`
> hutool-extra crate：87 个 `.rs` 文件

迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 的反射 / 字节码 / Spring 容器 / JavaMail / Velocity / JSch 分别映射为：
trait 对象、`serde`、axum 桥接、`lettre`、`handlebars_rust`、`russh`。

状态图例：✅ 已迁移并有测试 / 🔀 语义已迁移但合并 / ⬜ 未迁移 / 🚫 不迁移 / 🆕 Rust 特有
