# hutool-cache → hutool-cache 功能语义迁移对照表

基线：Hutool **5.8.x** `hutool-cache`（`cn.hutool.cache.*` 19 个类）。
迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 的 `ConcurrentHashMap` 映射为 `moka::sync::Cache`；
`ScheduledExecutorService` 映射为 `tokio` 定时器；
`ReferenceQueue` 映射为 `std::sync::Weak`；
`CacheListener` 映射为 trait 对象；
`ReentrantReadWriteLock` 映射为 `tokio::sync::RwLock`。

状态图例：✅ 已迁移并有测试 / 🔶 语义等价但形态不同 / ⬜ 未迁移（路线图）/ 🚫 不迁移 / 🆕 Rust 特有
