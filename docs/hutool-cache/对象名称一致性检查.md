## 五、语义一致性检查

### ✅ 完全一致的语义

- 缓存基本 CRUD
- 监听器四事件（put/remove/expire/clear）
- 各种淘汰策略（FIFO/LFU/LRU）
- 定时过期清理
- 弱引用 key

### 🔶 形态不同

- `ConcurrentHashMap` → `moka::sync::Cache`
- `ReentrantReadWriteLock` → `tokio::sync::RwLock` 或 `parking_lot::RwLock`
- `StampedLock` → 自实现乐观读（无现成 crate）
- `WeakReference<K>` + `ReferenceQueue` → `std::sync::Weak` + 轮询
- `ScheduledExecutorService` → `tokio::time::interval`

### 🔀 合并未拆

- compat.rs 仍包含 12 个类，必须拆分（见 S1 路线图）

### 🆕 Rust 特有

- `CacheIntoIterator`、`SharedListener`、`ScheduledTimedCache`、`CacheConfig`、`PruneHandle`
