# hutool-aop 对象级对照表（验收清单）

基线：Hutool **5.8.x** `hutool-aop`，共 **11 个 Java 类**。
本文档与 `语义迁移对照表.md` 互补：语义表回答"功能有没有"，
本表回答"**每个 Java 对象落在哪个 Rust 文件**"，是结构拆分与补缺的验收清单。

## 目标工程结构

```
crates/hutool-aop/
├── Cargo.toml
└── src/
    ├── lib.rs                      # crate 门面 + Interceptor / InterceptorChain
    ├── interceptor.rs              # JdkInterceptor / CglibInterceptor / SpringCglibInterceptor（合并）
    ├── aop_tests.rs                # 内部单元测试
    │
    ├── aspects/                    # 切面实现
    │   ├── mod.rs
    │   ├── aspect.rs               # Aspect trait
    │   ├── simple_aspect.rs        # SimpleAspect
    │   ├── time_interval_aspect.rs # TimeIntervalAspect
    │   └── timing_event.rs         # TimingEvent（Rust 扩展）
    │
    ├── invocation/                 # 调用上下文
    │   ├── mod.rs
    │   ├── method.rs               # Method 抽象
    │   ├── invocation_handler.rs   # InvocationHandler trait
    │   └── handler_proxy.rs        # HandlerProxy（Rust 扩展）
    │
    └── proxy/                      # 代理工厂
        ├── mod.rs
        ├── proxy.rs                # Proxy
        ├── proxy_backend.rs        # ProxyBackend 枚举
        ├── proxy_factory.rs        # ProxyFactory trait
        ├── proxy_util.rs           # ProxyUtil 门面
        ├── jdk_proxy_factory.rs    # JdkProxyFactory
        ├── cglib_proxy_factory.rs  # CglibProxyFactory
        └── spring_cglib_proxy_factory.rs # SpringCglibProxyFactory
```

## 命名与组织规则

1. 目录、文件名一律 snake_case；类型 PascalCase；方法 snake_case
2. **每个 .rs 文件只对应一个 Java 对象**；接口去 Java 匈牙利前缀（`InvocationHandler` → `InvocationHandler`）
3. `mod.rs` 只做模块声明与 re-export，**禁止定义任何类型/逻辑**
4. Java 多层嵌套包只要求**最后一层目录**完全对齐
5. 每个文件头部必须有中文 doc 注释：说明对应 Java 类的全限定名、核心职责
6. 方法级中文注释从 Java 源码同步翻译

## 3. Interceptor 包（`cn.hutool.aop.interceptor`）（3）

| Java 类 | 目标文件 | 状态 | 说明 |
|---------|----------|------|------|
| `JdkInterceptor` | `interceptor.rs` | 🔀 | JDK 拦截器，与 CglibInterceptor 合并 |
| `CglibInterceptor` | `interceptor.rs` | 🔀 | CGLIB 拦截器，与 JdkInterceptor 合并 |
| `SpringCglibInterceptor` | `interceptor.rs` | 🔀 | Spring CGLIB 拦截器，与 JdkInterceptor 合并 |
| `Interceptor` trait | `lib.rs` | 🆕 | 参数化拦截器 trait（替代三个 Java 拦截器抽象） |
| `InterceptorChain` | `lib.rs` | 🆕 | 拦截器链数据结构 |

**合并理由**：Java 三个拦截器都实现 `java.lang.reflect.InvocationHandler`，
在 Rust 中统一为 `Interceptor<C, R, E>` trait，由 `ProxyFactory` 决定使用
哪个后端，从而无需为每个后端维护独立 interceptor 文件。
