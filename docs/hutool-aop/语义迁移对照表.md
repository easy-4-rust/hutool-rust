# hutool-aop → hutool-aop 功能语义迁移对照表

基线：Hutool **5.8.x** `hutool-aop`（`cn.hutool.aop.*` 11 个类）。
迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 的 JDK `Proxy` / CGLIB 字节码生成分别映射为：trait 对象 + `ProxyBackend` 枚举；
`java.lang.reflect.InvocationHandler` 映射为参数化 `Interceptor<C, R, E>` trait；
`@Aspect` 注解映射为 procedural macro（参考 `sa-token-macro`）。

状态图例：✅ 已迁移并有测试 / 🔶 语义等价但形态不同 / ⬜ 未迁移（路线图）/ 🚫 不迁移 / 🆕 Rust 特有

## 一、顶层 API

| Java 类/方法 | 语义 | Rust 实现 | 状态 |
|---|---|---|---|
| `ProxyUtil.newProxyInstance(classLoader, interfaces, invocationHandler)` | 创建 JDK 代理实例 | `ProxyUtil::new_proxy_instance(target, aspect, backend)` | ✅ |
| `ProxyUtil.proxy(target, aspect)` | 创建 CGLIB 代理实例 | 同上，通过 `ProxyBackend` 切换 | ✅ |
| `ProxyUtil.invoke(target, method, args, aspect)` | 直接调用织入切面 | `ProxyUtil::invoke(target, method_name, args, aspect)` | ✅ |

## 二、Proxy 后端

| Java 类 | 语义 | Rust 实现 | 状态 |
|---|---|---|---|
| `ProxyFactory` | 代理工厂抽象 | `ProxyFactory` trait | ✅ |
| `JdkProxyFactory` | JDK 动态代理（接口代理） | `JdkProxyFactory` struct | ✅ |
| `CglibProxyFactory` | CGLIB 子类化代理（类代理） | `CglibProxyFactory` struct | ✅ |
| `SpringCglibProxyFactory` | Spring AOP 包装的 CGLIB | `SpringCglibProxyFactory` struct | 🔶 无 Spring 容器，做兼容占位 |
| `Proxy`（隐含） | 代理实例 | `Proxy` struct | 🆕 |
| `ProxyBackend`（隐含） | 后端选择 | `ProxyBackend` enum（Jdk/Cglib/SpringCglib） | 🆕 |

## 三、Interceptor

| Java 类 | 语义 | Rust 实现 | 状态 |
|---|---|---|---|
| `JdkInterceptor` | JDK `InvocationHandler` 适配 | `Interceptor<C, R, E>` trait | 🔀 合并 |
| `CglibInterceptor` | CGLIB `MethodInterceptor` 适配 | 同上 | 🔀 合并 |
| `SpringCglibInterceptor` | Spring `MethodInterceptor` 适配 | 同上 | 🔀 合并 |
| `InterceptorChain`（隐含） | 拦截器链 | `InterceptorChain<C, R, E>` struct | 🆕 |
| `Interceptor.before/after/afterThrowing` | 拦截器回调 | `intercept` trait 方法 | 🆕 |

**合并说明**：Java 三个 `*Interceptor` 类都用于将 Hutool 的 `Aspect` 适配为
各自运行时框架的回调接口（`InvocationHandler` / `MethodInterceptor`）。
Rust 无此异构运行时差异，因此统一为单一 `Interceptor<C, R, E>` trait，
由 `ProxyFactory` 决定如何驱动它。

## 十一、Aspect 语义详解

### SimpleAspect

```java
// Java
public class SimpleAspect implements Aspect {
    @Override
    public boolean before(Object target, Method method, Object[] args) {
        return true; // 继续执行
    }
    @Override
    public boolean after(Object target, Method method, Object[] args) {
        return true;
    }
    @Override
    public boolean afterThrowing(Object target, Method method, Object[] args, Throwable e) {
        return true;
    }
}
```

```rust
// Rust
pub struct SimpleAspect;

impl Aspect for SimpleAspect {
    fn before(&self, _target: &dyn Any, _method: &str, _args: &[Box<dyn Any>]) -> bool {
        true
    }
    fn after(&self, _target: &dyn Any, _method: &str, _args: &[Box<dyn Any>]) -> bool {
        true
    }
    fn after_throwing(&self, _target: &dyn Any, _method: &str, _args: &[Box<dyn Any>], _e: &dyn std::error::Error) -> bool {
        true
    }
}
```

### TimeIntervalAspect

```java
// Java
public class TimeIntervalAspect extends SimpleAspect {
    @Override
    public boolean before(Object target, Method method, Object[] args) {
        startTime.put(System.nanoTime());
        return super.before(target, method, args);
    }
    @Override
    public boolean after(Object target, Method method, Object[] args) {
        long endTime = System.nanoTime();
        long cost = endTime - startTime.get();
        log.info("method [{}] cost {} ns", method.getName(), cost);
        return super.after(target, method, args);
    }
}
```

```rust
// Rust
pub struct TimeIntervalAspect;

impl Aspect for TimeIntervalAspect {
    fn before(&self, _target: &dyn Any, _method: &str, _args: &[Box<dyn Any>]) -> bool {
        // 记录开始时间
        TIMING_EVENTS.with(|e| e.set(Instant::now()));
        true
    }
    fn after(&self, _target: &dyn Any, method: &str, _args: &[Box<dyn Any>]) -> bool {
        let cost = TIMING_EVENTS.with(|e| e.get().elapsed());
        log::info!("method [{}] cost {:?}", method, cost);
        true
    }
}
```

## 十二、Proxy 后端差异

| 后端 | Java 触发条件 | Rust 实现 |
|------|--------------|-----------|
| JDK | 目标对象实现接口 | 用 `dyn Trait` + 自实现包装 |
| CGLIB | 目标对象无接口 | 静态分发（trait 对象转换） |
| SpringCGLIB | Spring 容器内 | 兼容占位（标记为 🔶） |

## 十三、Interceptor 链

Java 无显式链；Rust 侧扩展：

```rust
let chain = InterceptorChain::new()
    .chain(Box::new(LoggingInterceptor))
    .chain(Box::new(TimingInterceptor));

ProxyUtil::new_proxy_instance(target, aspect, ProxyBackend::Jdk, chain)?;
```

`InterceptorChain` 提供 `before` / `after` / `after_throwing` 的链式调用，
每个拦截器独立维护自己的状态。
