## 五、语义一致性检查

### ✅ 完全一致的语义

- 代理工厂 trait 接口签名
- 切面 before/after/afterThrowing 三阶段
- 计时切面记录方法执行耗时
- `ProxyUtil` 三个静态方法

### 🔶 形态不同

- `Method`：Java 使用 `java.lang.reflect.Method`，Rust 使用 `Method { name: String, param_types: Vec<TypeId> }`
- `Object[] args` → `Vec<Box<dyn Any>>`
- `InvocationHandler.invoke(...)` → `InvocationHandler::invoke(&self, method, args) -> Result<...>`

### 🔀 合并未拆

- 三个 Java Interceptor 合并到 `interceptor.rs`
- 拆分为 `interceptor/jdk_interceptor.rs` 等三个独立文件的工作未启动

### 🆕 Rust 特有

- `ProxyBackend` 枚举
- `HandlerProxy<T>` 泛型代理骨架
- `Interceptor<C, R, E>` 参数化 trait
- `InterceptorChain<C, R, E>` 链式结构
- `TimingEvent` 计时事件
