# hutool-http → hutool-http 全量迁移路线图

> 版本：v1.0（2026-07-27）｜基线：Hutool **5.8.x**（`hutool-http`）
> 仓库：easy-4-rust/hutool-rust @ main ｜ 本文档随代码同步维护，每阶段完成时更新

## 一、总目标

以 Hutool 5.8.x 的 `hutool-http` 模块为蓝本，实现功能语义完全对齐的
`hutool-http` crate。基线 Java 包 `cn.hutool.http` 共 **62 个非 `package-info` 类**，
覆盖 HTTP 客户端、请求/响应、User-Agent 解析、SSL、TLS、Cookie、SOAP
WebService、嵌入式 HTTP Server 等完整生态。

### 设计原则

1. **功能语义对齐，实现方式 Rust 化**：Java `HttpClient` / `HttpURLConnection` →
   `reqwest` 异步客户端；`hutool-http` 的链式 `HttpRequest.setXxx()` →
   `reqwest::RequestBuilder` 的同义链式 API；Java 反射 → trait 对象
2. **每个 `.rs` 文件只对应一个 Java 对象**：对齐 `hutool-rust` 的一文件一对象规范
3. **所有公开类型必须有中文文档注释**：结构体、枚举、trait、方法、字段
4. **模块路径 snake_case**，类型 PascalCase，方法 snake_case
5. **同步接口必须存在**：hutool-rust 提供 `HttpRequest::send()` 同步包装
6. **安全策略分离**：`UrlPolicy` 独立 trait，避免引入 SSRF 漏洞

## 二、跨切语义映射

| Java / JVM 概念 | Rust 实现 | 备注 |
|---|---|---|
| Apache HttpClient / HttpURLConnection | `reqwest::Client` | 同步 + 异步双 API |
| Hutool `HttpRequest` 链式 | `reqwest::RequestBuilder` + 自有 `HttpRequest` 门面 | 兼容链式 |
| Hutool `HttpResponse` | `reqwest::Response` + `HttpResponse` 包装 | 提取 status / body |
| `javax.net.ssl.SSLContext` | `reqwest::tls` + `rustls` | 默认 rustls |
| `java.net.HttpCookie` | `cookie` crate | 标准 Cookie 解析 |
| `java.net.URLConnection` | `reqwest::Url` | URL 解析 |
| `User-Agent` 解析 | `uap-rust` crate | 浏览器/引擎/OS 解析 |
| `org.jsoup` HTML 过滤 | `scraper` 或 `html5ever` | 提供 `feature = "html"` |
| `MimeType` / `ContentType` | `mime` crate | MIME 常量 |
| `org.eclipse.jetty` Server | `hyper` + `http-body-util` | 自带 `SimpleServer` |

## 七、风险评估

| 风险 | 影响 | 对策 |
|------|------|------|
| `reqwest` API 变更 | 频繁 minor 升级 | 锁版本 + CI |
| `useragent` 解析精度 | UA 字符串无穷 | 复用 `uap-rust` 正则 |
| `hyper` server 生命周期 | leak 风险 | `with_graceful_shutdown` |
| 同步 API 缺失 | 部分调用方阻塞 | 提供 `reqwest::blocking` feature |
| TLS 协议版本 | 旧设备兼容 | `TlsProtocol` 枚举透传 |
