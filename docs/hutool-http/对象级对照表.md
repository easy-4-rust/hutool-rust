## 命名与组织规则

1. 目录、文件名一律 snake_case；类型 PascalCase；方法 snake_case
2. **每个 `.rs` 文件只对应一个 Java 对象**（除 crate 门面 / 集成层）
3. `mod.rs` 只做模块声明与 re-export，**禁止定义任何类型/逻辑**
4. Java 多层嵌套包只要求**最后一层目录**完全对齐
5. 每个文件头部必须有中文 doc 注释：说明对应 Java 类的全限定名、核心职责
6. 方法级中文注释从 Java 源码同步翻译

## 待拆分（🔀）说明

- `cookie/mod.rs` 同时包含 `GlobalCookieManager` + `ThreadLocalCookieStore`，
  计划 S2.1 拆为 `cookie/global_cookie_manager.rs` + `cookie/thread_local_cookie_store.rs`
- `server/filter.rs` 同时包含 `HttpFilter` + `SimpleFilter` + `ExceptionFilter`，
  计划 S6.1 拆为三个独立文件
- `server/root_action.rs` 内联 `ActionHandler` 逻辑，
  计划 S6.1 提取为 `server/action_handler.rs`
- `ssl/` 子包中 `DefaultSSLFactory` + `DefaultSSLInfo` 由 `reqwest::tls` 取代，
  保留 `config/tls_protocol.rs` 枚举作为配置入口
