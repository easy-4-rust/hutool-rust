# hutool-http → hutool-http 功能语义迁移对照表

> 基线：Hutool **5.8.x**（`hutool-http` 模块），已覆盖 HTTP/1.1、WebSocket-over-HTTP、
> multipart/form-data、SOAP 1.1/1.2、User-Agent 解析、嵌入式 HTTP Server 等场景。
>
> 迁移原则：**功能语义对齐，实现方式 Rust 化**。
> Java 的 `HttpURLConnection` / Apache HttpClient / Hutool `HttpRequest` 链式
> 分别映射为：`reqwest::Client` / `reqwest::RequestBuilder` / 自有 `HttpRequest` 门面。

## 跨切语义映射

| Java / JVM 概念 | Rust 实现 | 备注 |
|---|---|---|
| Apache HttpClient / OkHttp / `HttpURLConnection` | `reqwest` | 同步 + 异步双 API |
| `javax.net.ssl.SSLContext` / `SSLSocketFactory` | `reqwest::tls` + `rustls` | 默认 rustls |
| Hutool `HttpRequest` 链式 | `HttpRequest` 门面 + `reqwest::RequestBuilder` | 兼容链式 |
| Hutool `HttpResponse` | `HttpResponse` 包装 | 提取 status / body |
| `java.net.HttpCookie` | `cookie` crate | RFC 6265 |
| `java.net.URL` | `reqwest::Url`（re-export） | URL 解析 |
| `org.jsoup` HTML 过滤 | `html5ever` / `scraper` | `feature = "html"` |
| `MimeType` / `ContentType` | `mime` crate | MIME 常量 |
| `org.eclipse.jetty` Server | `hyper` + `http-body-util` | 自带 `SimpleServer` |
| `User-Agent` 解析（自研） | `uap-rust` crate | 浏览器/引擎/OS |
