## 命名与组织规则

1. 目录、文件名一律 snake_case；类型 PascalCase；方法 snake_case
2. **每个 .rs 文件只对应一个 Java 对象**
3. `mod.rs` 只做模块声明与 re-export
4. Java 多层嵌套包只要求**最后一层目录**完全对齐
5. 每个文件头部必须有中文 doc 注释
6. 方法级中文注释从 Java 源码同步翻译

## 七、Rust 扩展类型溯源

### `MatchOptions`（Rust 扩展）

Java 用散落字段表达：

```java
private boolean overlap = false;  // 是否允许重叠匹配
private int minLength = 1;       // 最小匹配长度
```

Rust 用结构体集中管理：

```rust
pub struct MatchOptions {
    pub overlap: bool,
    pub min_length: usize,
}

impl Default for MatchOptions {
    fn default() -> Self {
        Self { overlap: false, min_length: 1 }
    }
}
```

### `DfaError`（Rust 扩展）

Java 用 `cn.hutool.core.exceptions.UtilException`：

```java
throw new UtilException("Word tree is empty");
```

Rust 用枚举统一所有错误：

```rust
pub enum DfaError {
    EmptyTree,
    InvalidJson(String),
    Serialize(String),
    IoError(std::io::Error),
}
```
