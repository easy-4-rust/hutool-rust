# hutool-dfa → hutool-dfa 功能语义迁移对照表

基线：Hutool **5.8.x** `hutool-dfa`（`cn.hutool.dfa.*` 5 个类）。
迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 的 `HashMap<Character, Map>` 嵌套映射为 `HashMap<char, WordTree>`；
`ArrayList<FoundWord>` 映射为 `Vec<FoundWord>`；
`StringBuilder` 映射为 `String` + `push_str`。

状态图例：✅ 已迁移并有测试 / 🔶 语义等价但形态不同 / ⬜ 未迁移（路线图）/ 🚫 不迁移 / 🆕 Rust 特有

| Java 类 | 语义 | Rust 实现 | 状态 |

| `FoundWord` | 匹配结果（word + start + end） | `FoundWord` struct | ✅ |

## 八、API 详解

### `WordTree`

```rust
pub struct WordTree {
    // ...
}

impl WordTree {
    pub fn new() -> Self;
    pub fn add_word(&mut self, word: &str);
    pub fn match_all(&self, text: &str) -> Vec<FoundWord>;
    pub fn is_match(&self, text: &str) -> bool;
    pub fn clear(&mut self);
}
```

- 内部使用 `HashMap<char, WordTree>` 嵌套
- 支持中文/英文/混合
- 支持重叠匹配（`MatchOptions::overlap(true)`）

### `FoundWord`

```rust
pub struct FoundWord {
    pub word: String,   // 匹配到的敏感词
    pub start: usize,   // 起始位置（按 char 索引）
    pub end: usize,     // 结束位置（按 char 索引，不含）
}
```

### `SensitiveUtil`

```rust
impl SensitiveUtil {
    pub fn serialize(tree: &WordTree) -> Result<String, DfaError>;
    pub fn deserialize(json: &str) -> Result<WordTree, DfaError>;
    pub fn get_found_all(text: &str, tree: &WordTree) -> Vec<FoundWord>;
    pub fn get_found_first(text: &str, tree: &WordTree) -> Option<FoundWord>;
}
```

### `SensitiveProcessor`

```rust
pub trait SensitiveProcessor: Send + Sync {
    fn process(&self, text: &str, replacement: char) -> String;

```

### `DefaultSensitiveProcessor`

```rust
    }

```

## 十一、与 Java 行为一致性

### WordTree 匹配行为

| 场景 | Java 行为 | Rust 行为 |
|------|----------|----------|
| 单个敏感词 | `matchAll` 返回一个 `FoundWord` | `match_all` 返回一个 `FoundWord` |
| 重叠敏感词 | 默认返回所有 | 通过 `MatchOptions::overlap(true)` 启用 |
| 嵌套敏感词 | 短词优先 | 一致 |
| 大小写敏感 | 默认敏感 | 一致 |
| 中英文混合 | 支持 | 支持 |
| 空输入 | 返回空 | 返回空 |
| 不匹配 | 返回空 | 返回空 |

### 序列化格式

Java: `{"a":{"b":{...}}}`（嵌套 HashMap → JSON）
Rust: `{"a":{"b":{...}}}`（一致）
