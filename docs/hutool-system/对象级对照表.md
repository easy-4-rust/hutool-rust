# hutool-system 对象级对照表（验收清单）

基线：hutool-system **5.8.43+**，Java 源共 **20+ 个类**（顶级 13 个 + oshi
子包 9 个）。本文档回答"**每个 Java 对象落在哪个 Rust 文件**"。

## 目标工程结构

```
hutool-system/
├── Cargo.toml                            # crate 根
└── src/
    ├── lib.rs                            # crate 门面 + SystemSnapshot（🆕）
    │
    ├── compat.rs                         # ✅ 当前单源 dump，待拆分
    │
    └── oshi/                             # OSHI 兼容子模块（✅ 已正确拆分）
        ├── mod.rs                        # 模块声明 + 公共 re-export
        ├── cpu_ticks.rs                  # CpuTicks
        ├── cpu_info.rs                   # CpuInfo
        ├── process_info.rs               # ProcessInfo
        ├── memory_info.rs                # MemoryInfo
        ├── disk_info.rs                  # DiskInfo
        ├── network_info.rs               # NetworkInfo
        ├── sensor_info.rs                # SensorInfo
        ├── hardware_info.rs              # HardwareInfo
        └── oshi_util.rs                  # OshiUtil
```

## 命名与组织规则

1. 目录、文件名一律 snake_case；类型 PascalCase；方法 snake_case
2. **每个 .rs 文件只对应一个 Java 对象**（顶级 / 公共对象）
3. `mod.rs` 只做模块声明与 re-export，**禁止定义任何类型/逻辑**
4. Java `oshi` 子包映射到 `oshi/` 子目录（保留最后一层目录名）
5. 每个文件头部必须有中文 doc 注释：说明对应 Java 类的全限定名、核心职责
6. **单源 dump 治理**：当前 `compat.rs` 单源 dump 违规，已列入路线图 S6

## 三、不迁移（Java 生态特有）

| Java 类 | 原因 | Rust 替代 |
|---------|------|----------|
| `cn.hutool.system.SystemUtil.append(StringBuilder, ...)` | Java 字符串构造 | 显式 `write!` |
| `cn.hutool.system.SystemUtil.get(String, boolean)` 反射 | Java `System.getProperty` | `env::var` |
| `cn.hutool.system.SystemUtil.set(String, String)` | Java `System.setProperty` | 不提供 |
| `cn.hutool.system.SystemUtil.dumpSystemProperties` | Java Properties 序列化 | 不提供 |
| `cn.hutool.system.SystemUtil.getJavaInfo` | Java 反射 | `JavaInfo` struct |
| `cn.hutool.system.SystemUtil.getJvmInfo` | Java 反射 | `JvmInfo` struct |
| `cn.hutool.system.SystemUtil.getUserInfo` | Java 反射 | `UserInfo` struct |
| `cn.hutool.system.SystemUtil.getHostInfo` | Java `InetAddress` | `HostInfo` struct |
| `cn.hutool.system.SystemUtil.getManagementInfo` | Java `Runtime` | `ManagementInfo` struct |
| `cn.hutool.system.SystemUtil.getRuntimeInfo` | Java `Runtime` | `RuntimeInfo` struct |
| `cn.hutool.system.SystemUtil.getCompilationInfo` | Java 编译时间 | `CompilationInfo` struct |
| `cn.hutool.system.SystemUtil.get(SystemPropsKeys, T)` 泛型 | Java 泛型 | 显式 `get_xxx` |
| `serialVersionUID` | Java 序列化 | 不适用 |
| `Serializable` 实现 | Java 序列化 | 不适用 |
| `OsInfo.isWindows2000/XP/7/8/10/11` 单独谓词 | Java 简化 | 合并 `is_windows()` + `version` 字符串判断 |
| `OsInfo.isAix/HP-UX/Irix/OS2/Solaris/SunOS/ME/NT` | 旧 OS | 仍保留为可选谓词 |
| `META-INF/services/...` | Java SPI | 不适用 |
