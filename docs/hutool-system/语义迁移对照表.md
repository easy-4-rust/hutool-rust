# hutool-system 功能语义迁移对照表

基线：hutool-system **5.8.43+**，覆盖 20+ 个类（顶级 13 个 + oshi 子包 9 个）。
本文档回答"功能有没有"，与 `对象级对照表.md` 互补。

迁移原则：**功能语义对齐，实现方式 Rust 化**。Java `System.getProperty` 反射
+ OSHI 平台调用 全部映射为：跨平台 `sysinfo` + `env::var` + `cfg!(windows)`
编译期分支。

状态图例：✅ 已迁移并有测试 / 🔀 已合并待拆 / ⬜ 未迁移（路线图）/ 🚫 不迁移 / 🆕 Rust 特有
