# hutool-script 功能语义迁移对照表

基线：hutool-script **5.8.43+**，4 个核心类（顶级包）。本文档回答"功能有没有"，
与 `对象级对照表.md` 互补。

迁移原则：**功能语义对齐，实现方式 Rust 化**。JSR-223 反射 / SPI / 线程
ThreadLocal 全部映射为：显式枚举 + 强类型结构体 + 沙箱资源限制。

状态图例：✅ 已迁移并有测试 / 🔀 已合并待拆 / ⬜ 未迁移（路线图）/ 🚫 不迁移 / 🆕 Rust 特有

## 六、沙箱安全

| 维度 | Java | Rust | 状态 |
|------|------|------|------|
| 内部 `eval` 函数 | Nashorn 支持 | Rhai 禁用 `eval` | 🆕 |
| 文件 I/O | 受 SecurityManager 控制 | Rhai 不暴露文件 API | ✅ |
| 网络 I/O | SecurityManager | Rhai 不暴露 | ✅ |
| 进程执行 | SecurityManager | Rhai 不暴露 | ✅ |
| 类反射 | 可用 | **Rhai 不可用** | ✅ |
| 资源限制 | 无内置 | `ScriptLimits` 强制 | 🆕 |
| 内存限制 | JVM 设置 | Rhai 内部限制 + 数组/字符串上限 | 🆕 |
| 脚本大小 | 无限制 | 1 MiB Reader 上限 | 🆕 |
| SecurityManager | JDK 17+ 已弃用 | 不需要 | 🆕 |
