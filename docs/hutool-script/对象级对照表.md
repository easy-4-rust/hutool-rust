# hutool-script 对象级对照表（验收清单）

基线：hutool-script **5.8.43+**，Java 源共 **4 个核心类**（顶级包），无子包。
hutool-script 是 hutool 中最小的模块之一，只在 `cn.hutool.script` 包下导出
4 个公共类型 + 1 个 package-info。

## 目标工程结构

```
hutool-script/
├── Cargo.toml                            # crate 根
└── src/
    ├── lib.rs                            # crate 门面：pub use + ScriptError / ScriptLimits 类型别名
    │
    ├── script_util.rs                    # cn.hutool.script.ScriptUtil
    ├── script_runtime_exception.rs       # cn.hutool.script.ScriptRuntimeException
    │
    ├── full_support_script_engine.rs     # cn.hutool.script.FullSupportScriptEngine
    ├── javascript_engine.rs              # cn.hutool.script.JavaScriptEngine
    ├── script_engine_factory.rs          # cn.hutool.script.ScriptEngineFactory
    │
    ├── script_language.rs                # cn.hutool.script.ScriptLanguage
    ├── bindings.rs                       # cn.hutool.script.Bindings
    ├── script_context.rs                 # cn.hutool.script.ScriptContext
    ├── script_scope.rs                   # cn.hutool.script.Scope（Java: ScriptContext 内部 Scope）
    ├── compiled_script.rs                # cn.hutool.script.CompiledScript
    └── script_interface.rs               # cn.hutool.script.ScriptInterface
```

> **注意**：Java `cn.hutool.script` 顶级包**没有子包**，所有类直接平铺到 `src/` 根。
> **禁止**使用 `compat/`、`hutool/` 等中间目录。

## 命名与组织规则

1. 目录、文件名一律 snake_case；类型 PascalCase；方法 snake_case
2. **每个 .rs 文件只对应一个 Java 对象**（顶级 / 公共对象）
3. `mod.rs` 仅出现在子包（hutool-script 顶级包无子包，因此无 mod.rs）
4. **完全平铺**：与 `cn.hutool.script` 顶级包 1:1 对齐，无 compat 层级
5. Java `javax.script.*` 抽象通过 crate 根提供 trait/struct（如 `ScriptContext`、`CompiledScript`）
6. 每个文件头部必须有中文 doc 注释：说明对应 Java 类的全限定名、核心职责
7. **单源 dump 治理**：必须 0 个 `compat.rs` / `compat/` 集中定义桶

## 三、不迁移（Java 生态特有）

| Java 类 | 原因 | Rust 替代 |
|---------|------|----------|
| `cn.hutool.script.package-info` | 包级 javadoc | 文档系统承担 |
| `javax.script.ScriptEngineManager` | 运行时反射 | `ScriptLanguage` 编译期枚举 |
| `META-INF/services/...` SPI 文件 | Java SPI 描述符 | 无需 |
| `javax.script.ScriptContext.setAttribute` | Java Map 风格 | `Bindings::insert` |
| `javax.script.ScriptContext.getAttribute` | Java Map 风格 | `Bindings::get` |
| `javax.script.ScriptContext.removeAttribute` | Java Map 风格 | `Bindings::remove` |
| JDK Nashorn / GraalJS | JDK 引擎 | Rhai 替代 |
| JSR-223 兼容层 | Java 规范 | 不再适用 |
