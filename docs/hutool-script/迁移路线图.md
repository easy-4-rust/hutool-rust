> 版本：v1.0（2026-07-27）｜基线：hutool **5.8.43+**（hutool-script）
> 仓库：easy-4-rust/hutool-rust @ dev ｜ 本文档随代码同步维护

## 一、总目标

以 hutool-script 为蓝本实现功能语义对齐的 hutool-script Rust crate：覆盖 Java
端 JSR-223（`javax.script`）脚本抽象，通过 sandboxed **Rhai** 引擎实现
JavaScript 兼容入口，并预留 **Python / Lua / Groovy** 三个 optional 后端。

### 设计原则

1. **功能语义对齐，实现方式 Rust 化**：`javax.script` 反射 / SPI 机制 →
   显式 `ScriptLanguage` 枚举 + trait object；`ScriptException` 检查异常 →
   `ScriptRuntimeException` 非检查异常；`Bindings` 弱类型 → 强类型 `BTreeMap`
2. **每个 .rs 文件只对应一个 Java 对象**：对齐 hutool-rust 一文件一对象规范
3. **公开 API 必须有中文文档注释**：结构体、枚举、trait、方法、字段
4. **沙箱安全**：禁用 `eval`、限制操作步数 / 字符串长度 / 数组容量
5. **显式作用域**：不再依赖 Java 的 `ScriptContext` ENGINE_SCOPE / GLOBAL_SCOPE
   默认全局，所有 bindings 通过 `ScriptContext` 显式传递
6. **资源保护**：脚本 Reader 最多读取 1 MiB，防止恶意脚本撑爆内存

## 四、与 Java hutool-script 的主要差异

| 维度 | Java 实现 | Rust 实现 | 原因 |
|------|----------|----------|------|
| 引擎加载 | `ScriptEngineManager` 反射 JDK ServiceLoader | 编译期 `ScriptLanguage` 枚举 | Rust 无 SPI |
| `Bindings` 弱类型 | `Map<String, Object>` | `BTreeMap<String, Dynamic>` | 类型安全 |
| `ScriptContext` ENGINE/GLOBAL | ThreadLocal 默认值 | 显式 `ScriptContext` 必传 | 避免全局污染 |
| 资源限制 | 无 | `ScriptLimits` 强制约束 | 沙箱 |
| 脚本大小限制 | 无 | Reader 上限 1 MiB | 防 DoS |
| `eval` 内部脚本 | Nashorn 支持 | Rhai `disable_symbol("eval")` | 安全 |
| 异常 | `ScriptException`（检查）+ `ScriptRuntimeException`（非检查） | `ScriptError`（内部）+ `ScriptRuntimeException`（公开） | thiserror |
| `Invocable.getInterface` | 反射生成代理 | `ScriptInterface` 显式调用 | 无反射 |
| 编译/执行分离 | `Compilable` 接口 | `CompiledScript` struct | 类型安全 |
| 默认引擎 | JDK Nashorn | Rhai | Nashorn JDK15+ 已移除 |
| 异步 | 同步 | 同步（脚本不阻塞） | 嵌入式 |
| 文件 I/O | 可用 | **禁用** | 沙箱 |
| 网络 I/O | 可用 | **禁用** | 沙箱 |
| 进程执行 | 可用 | **禁用** | 沙箱 |

## 五、风险与限制

1. **沙箱不可绕过**：禁用 `eval`、`FileSystem`、`Network`、`Process`；如需开启需
   自行注册 Rhai 函数
2. **Rhai 表达式能力有限**：与 JavaScript 完整规范不兼容（不支持 `async/await`、
   `Proxy`、`WeakRef`），需先在代码中约束
3. **Reader 1 MiB 上限**：超大脚本请改用 `compile(&str)`
4. **编译期类型检查**：脚本类型错误运行时报 `ScriptError::TypeMismatch`
5. **Python/Lua/Groovy 不可用**：当前仅 Rhai 可用；其他语言返回错误
