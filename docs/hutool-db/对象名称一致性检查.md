## 三、Rust 特有（无 Java 对偶）

| Rust 类型 | 来源 / 作用 |
|-----------|------------|
| `PageRequest` | 编译期校验分页参数（替代 `Page.of(0, 0)` 抛异常） |
| `Page<T>` | 通用分页结果，泛型版本 |
| `PoolConfig` | sqlx pool 统一策略 |
| `DbError` | 顶层错误枚举（crate 内 thiserror 统一） |
| `ConditionValue` | 条件值的 Rust 化封装（支持 `serde_json::Value`） |
| `Join` | JOIN 类型枚举（LEFT/RIGHT/INNER/FULL） |
| `DbResult<T>` | 顶层结果别名（`Result<T, DbRuntimeError>`） |

## 四、命名规范说明

1. **PascalCase ↔ snake_case**：所有 Java 类名转 Rust 文件名时统一转 snake_case
2. **缩写词全大写**：Java 的 `DS` / `Db` / `DB` 在 Rust 中同样保持大写，
   但作为文件名时仍转 snake_case（如 `ds_factory.rs`），作为类型名时
   PascalCase 拼接（如 `DsFactory`、`DbConfig`）
3. **`Page` 重名规避**：Java 端只有 `Page`；Rust 端为了表达"编译期强类型分页"
   引入 `PageRequest` / `Page<T>`，于是 `Page` 改名为 `HutoolPage` 保留 Hutool
   对齐语义
4. **`Impls.rs` 集中方言**：Java 端每个方言一个文件，Rust 端为节省维护成本
   把 10 个方言合并到 `dialect/impls.rs`，每个方言一个 struct

## 五、类型风格说明

- Java `interface` → Rust `trait`
- Java `abstract class` → Rust `trait` + 默认实现 / `struct` + `impl`
- Java `extends X` → Rust `impl X for Y` / 字段组合
- Java `implements X, Y` → Rust `impl X for Z + impl Y for Z`
- Java `static final` 常量 → Rust `const` / `pub const`
- Java `enum` → Rust `enum`（同形）
- Java `Builder<T> build()` → Rust `*::new()` / `*::builder().build()`

## 六、错误体系映射

| Java | Rust |
|------|------|
| `DbRuntimeException extends RuntimeException` | `DbRuntimeError` enum（`thiserror::Error`） |
| `throws SQLException` | `Result<T, sqlx::Error>` |
| `null` 返回 | `Option<T>` |
| 自定义异常 | crate 顶层 `DbError` 枚举 |

## 七、生命周期 / 所有权映射

| Java | Rust |
|------|------|
| `Connection conn = ds.getConnection()` | `let mut conn = pool.acquire().await?` |
| `PreparedStatement ps = conn.prepareStatement(sql)` | `sqlx::query(sql).bind(...)` |
| `ResultSet rs = ps.executeQuery()` | `let row = sqlx::query_as::<_, T>(sql).fetch_one(...)` |
| `rs.close()` / `ps.close()` / `conn.close()` | `Drop` 自动调用 |
| `try (rs; ps; conn) { ... }` | `drop` + 显式 `?` 传播 |

## 八、总结

- **名称完全匹配**：60+ 个对象（snake_case ↔ PascalCase 一一对应）
- **合并**：5 个（DbUtil / Table / MongoFactory / RedisFactory / GlobalDSFactory）
- **改名**：2 个（Page → HutoolPage、StatementUtil → StatementWrapper）
- **不迁移**：5 个（JndiDSFactory / PooledConnection / ConnRunner / DbConnRunner / Row）
- **Rust 特有**：7 个（PageRequest / Page / PoolConfig / DbError / ConditionValue / Join / DbResult）

整体迁移率：**80%+** 类完整保留，剩余 20% 主要是 Java 生态特有或合并同类项。
