# hutool-db 全量迁移路线图

> 版本：v1.0（2026-07-27）｜基线：hutool **5.8.x**（hutool-db）
> 仓库：easy-4-rust/hutool-rust @ dev ｜ 本文档随代码同步维护，每阶段完成时更新

## 一、总目标

以 Hutool 5.8.x 的 `hutool-db` 模块为蓝本，实现**功能语义对齐、Rust 化实现**的
`hutool-db` crate。覆盖数据库连接池、方言、SQL 构建、CRUD 运行器、结果集
处理器、元数据查询、NoSQL 数据源（Mongo/Redis）等核心能力。

### 设计原则

1. **功能语义对齐，实现方式 Rust 化**：Java JDBC → sqlx；Druid / Hikari / DBCP
   → deadpool / sqlx-pool；MyBatis → rbatis（按需）；Dialect → sqlx::Database
   抽象
2. **每个 .rs 文件只对应一个 Java 对象**：对齐 liteflow-rust 的一文件一对象规范
3. **公开类型必须有中文文档注释**：结构体、枚举、trait、方法、字段
4. **模块路径 snake_case**，类型 PascalCase，方法 snake_case
5. **错误体系统一为 `thiserror::Error`**，避免 Java 异常体系下放到调用方
6. **充分利用 Rust 借用 + 所有权**，减少 Java 风格的 `setX` / `getX` 噪声
7. **异步优先**：底层使用 sqlx（tokio 运行时），但保持与同步接口的桥接

## 四、跨切语义映射

| Java 概念 | Rust 替代 | 说明 |
|-----------|----------|------|
| MyBatis | rbatis / sqlx | MyBatis 的 XML 映射 → rbatis 宏；纯 SQL → sqlx |
| Druid | deadpool / sqlx-pool | Druid 的 wall filter / stat filter 由应用层补 |
| JDBC | sqlx | `Connection` → sqlx `&mut Connection` / `&mut Transaction` |
| Dialect | sqlx::Database 抽象 + 自定义 trait | 方言差异在 sqlx 之上做薄包装 |
| HikariCP / DBCP / C3P0 | sqlx-pool | 同步连接池语义由 sqlx async pool 提供 |
| Properties (Java) | indexmap + config crate | 配置加载由 `config` crate 统一 |
| Hutool `Log` | `tracing` / `log` | 日志抽象统一对外接口 |
| Hutool `Setting` | `SettingsLoader`（config crate） | 配置中心 |

## 五、不迁移的内容

| Java 类型 | 不迁移原因 |
|-----------|----------|
| `nosql.mongo.MongoDS` 的 Java 反射 | sqlx-mongo 不需要；改为 `mongodb` crate 驱动 |
| `nosql.redis.RedisDS` 的 Jedis 依赖 | 改为 `redis` crate 驱动 |
| `ds.jndi.JndiDSFactory` | JNDI 是 Java EE 容器特性，Rust 工程中通过环境变量 / 配置中心替代 |
| `ds.c3p0.C3p0DSFactory` | C3P0 已停止维护，仅保留门面以提示用户改用 HikariCP（sqlx-pool） |
| `dialect.DriverNamePool` 的 H2 内存模式细节 | 由 sqlx 自行处理 |

## 六、风险与注意事项

1. **异步传染**：所有底层都是 `async`，调用方必须 `await`；同步包装通过
   `tokio::task::block_in_place` 提供
2. **方言实现**：oracle / dm / hana 等专有数据库的方言细节需要在 sqlx 之外
   手工补一些 `wrap_column` / `build_pagination_sql` 逻辑
3. **NoSQL feature gate**：避免在不需要 Mongo/Redis 的工程里被强制依赖
4. **实体反射**：Java `BeanHandler` / `BeanListHandler` 用反射；Rust 改为
   `serde` 反序列化，需要对象实现 `DeserializeOwned`
5. **分页方言**：MySQL `LIMIT ? , ?` 与 Oracle `ROWNUM` 与 SQL Server `OFFSET ?
   ROWS FETCH NEXT ? ROWS ONLY` 需在每个 Dialect 实现中显式分支
