# hutool-db → hutool-rust 功能语义迁移对照表

基线：hutool **5.8.x**（hutool-db）。迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 的 JDBC、Druid、HikariCP、MyBatis 分别映射为：sqlx、deadpool / sqlx-pool、
rbatis（按需）。

状态图例：✅ 已迁移并有测试 / 🔶 语义等价但形态不同 / ⬜ 未迁移（路线图）/ 🚫 不迁移

## 一、跨切语义映射

| Java 概念 | Rust 替代 | 适用位置 | 状态 |
|-----------|----------|----------|------|
| MyBatis | rbatis / sqlx | ORM 场景 | ✅ sqlx；rbatis feature-gate |
| Druid | deadpool / sqlx-pool | 监控型连接池 | 🔶 deadpool（feature） / sqlx-pool |
| HikariCP | sqlx-pool | 高性能连接池 | ✅ |
| JDBC | sqlx | 同步阻塞 | ✅ async |
| Dialect | sqlx::Database 抽象 + 自定义 trait | 方言差异 | ✅ |
| Properties | config crate + indexmap | 配置 | ✅ |
| Hutool Log | tracing / log | 日志 | ✅ |
| Hutool Setting | config crate | 配置中心 | ✅ |
