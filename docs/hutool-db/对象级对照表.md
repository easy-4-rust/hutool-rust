# hutool-db → hutool-rust 对象级对照表（验收清单）

基线：hutool **5.8.x**（hutool-db），覆盖 **80+ 个 Java 类**。
本文档与 `语义迁移对照表.md` 互补：语义表回答"功能有没有"，
本表回答"**每个 Java 对象落在哪个 Rust 文件**"，是结构拆分与补缺的验收清单。

## 命名与组织规则

1. 目录、文件名一律 `snake_case`；类型 `PascalCase`；方法 `snake_case`
2. **每个 .rs 文件只对应一个 Java 对象**；接口去 Java 匈牙利前缀
3. `mod.rs` 只做模块声明与 re-export，**禁止定义任何类型/逻辑**
4. Java 多层嵌套包只要求**最后一层目录**完全对齐
5. 每个文件头部必须有中文 doc 注释：说明对应 Java 类的全限定名、核心职责
6. 方法级中文注释从 Java 源码同步翻译

## 九、Rust 特有（无 Java 对偶）

| Rust 类型 | 来源 / 作用 |
|-----------|------------|
| `PageRequest` | 编译期校验分页参数（替代 `Page.of(0, 0)` 抛异常） |
| `Page<T>` | 通用分页结果，泛型版本 |
| `PoolConfig` | sqlx pool 统一策略 |
| `DbError` | 顶层错误枚举 |
| `ConditionValue` | 条件值的 Rust 化封装（支持 `serde_json::Value`） |
| `Join` | JOIN 类型枚举（LEFT/RIGHT/INNER/FULL） |
| `DbResult<T>` | 顶层结果别名 |

## 十、不迁移 / 合并 / 拆分说明

| Java 实体 | 处理方式 | 理由 |
|----------|----------|------|
| `JndiDSFactory` | 🚫 不迁移 | JNDI 是 Java EE 容器特性，Rust 工程用环境变量 |
| `PooledConnection` | 🚫 不迁移 | sqlx pool 已提供同等能力 |
| `ConnRunner` | 🔀 合并 | 与 `SqlConnRunner` 重复 |
| `Table` | 🔀 合并 | 与 `Column` 同处 `meta_types/column.rs` |
| `DbUtil` | 🔀 合并 | 静态工厂方法散落到各 `*::new()` 关联函数 |
| `StatementUtil` | 🔶 改名 | 改名 `jdbc_wrapper/statement_wrapper.rs` |
| `DbConnRunner` | 🚫 删除 | 测试辅助类 |
| `Row` | 🚫 不迁移 | sqlx 提供 |
| `PageUtil` | 🔶 重写 | Rust 改为 `PageRequest` 强类型 |
