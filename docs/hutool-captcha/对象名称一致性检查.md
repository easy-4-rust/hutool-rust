## 五、语义一致性检查

### ✅ 完全一致的语义

- 验证码四要素：createCode / write / getCode / verify
- 工厂方法 CaptchaUtil 四个 create_* 方法
- 字符集 `23456789ABCDEFGHJKLMNPQRSTUVWXYZ`
- 算术生成器四则运算
- GIF 帧延迟

### 🔶 形态不同

- `BufferedImage` → `RgbaImage`
- `Graphics2D` 绘制 → 像素级算法
- `AnimatedGifEncoder` → `gif` crate
- `java.util.Random` → `rand::thread_rng()`

### 🔀 合并未拆

- compat.rs 仍包含全部 11 个类，必须拆分（见 S1 路线图）

### 🆕 Rust 特有

- `PngRenderer` 像素级渲染器
- `AudioRenderer` / `AudioSpec` / `AudioSynthesizer` 音频验证码
- `RenderedCaptcha` 渲染产物封装
- `CodeGenerator` trait（与 Java 接口语义对齐但方法签名 Rust 化）
- `DEFAULT_ALPHABET` 常量
