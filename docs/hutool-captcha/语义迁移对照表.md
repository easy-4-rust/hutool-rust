# hutool-captcha → hutool-captcha 功能语义迁移对照表

基线：Hutool **5.8.x** `hutool-captcha`（`cn.hutool.captcha.*` 11 个类）。
迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 的 `java.awt.image.BufferedImage` 映射为 `image::RgbaImage`；
`java.awt.Graphics2D` 映射为自实现的 `PngRenderer`（像素级绘制）；
`AnimatedGifEncoder` 映射为 `gif` crate + 自定义帧延迟。

状态图例：✅ 已迁移并有测试 / 🔶 语义等价但形态不同 / ⬜ 未迁移（路线图）/ 🚫 不迁移 / 🆕 Rust 特有

## 七、Java 生成器算法

### `RandomGenerator`

- 默认字符集：`23456789ABCDEFGHJKLMNPQRSTUVWXYZ`（去除 0/O/1/I）
- 长度：默认 4
- 字符不重复（同一验证码内）

### `MathGenerator`

- 生成形如 `1+2=` 的算术题
- 支持 `+` `-` `*` `/` 运算符
- `/` 保证整除
- 验证时计算表达式结果

## 八、验证码实现细节

### `LineCaptcha`

- 字符：4 个
- 干扰：5 条随机直线
- 字符旋转：-30° 到 30°
- 默认尺寸：115x48

### `CircleCaptcha`

- 字符：4 个
- 干扰：5 个随机圆
- 字符旋转：-30° 到 30°
- 默认尺寸：115x48

### `ShearCaptcha`

- 字符：5 个
- 仿射变换矩阵（斜切）
- 字符旋转：-30° 到 30°
- 默认尺寸：115x48

### `GifCaptcha`

- 字符：5 个
- 多帧（每帧字符位置/颜色变化）
- 默认尺寸：115x48
- 帧数：默认 5-10
