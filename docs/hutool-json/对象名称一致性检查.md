## 四、业务逻辑一致性检查

### ✅ 完全一致的逻辑

- JSON 字符串解析（`JSONParser::from_str`）
- JSON 树形模型（`JSONObject` / `JSONArray` / `JSONNull`）
- Bean ↔ JSON 互转（`ObjectMapper`）
- XML ↔ JSON 互转（`JSONXMLParser` / `JSONXMLSerializer`）
- 字符串格式化（`JSONStrFormatter`）
- 错误聚合（`JsonError` 8 个变体）

### ⚠️ 部分一致的逻辑

- 数值精度：Java 用 `BigDecimal` / `BigInteger`，Rust 用 `f64` / `i64`（需配置）
- 时间格式：Java 用 `DateTimeFormatter`，Rust 用 `chrono::NaiveDateTime`
- Bean 互转：Java 反射访问字段，Rust 用 `serde` 派生

### ❌ 未实现的逻辑

- JSONPath 完整语法（递归 / 过滤 / 通配）
- 时间类型序列化（`TemporalAccessorSerializer`）
- 字段注解（`JSONGetter`）
- 自定义 toJSONString 协议（`JSONString`）
- 抽象基类 `JSON` 的多态分发
