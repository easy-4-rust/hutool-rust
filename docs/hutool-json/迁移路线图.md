# hutool-json → hutool-json 全量迁移路线图

> 版本：v1.0（2026-07-27）｜基线：Hutool **5.8.x**（`hutool-json`）
> 仓库：easy-4-rust/hutool-rust @ main ｜ 本文档随代码同步维护，每阶段完成时更新

## 一、总目标

以 Hutool 5.8.x 的 `hutool-json` 模块为蓝本，实现功能语义完全对齐的
`hutool-json` crate。基线 Java 包 `cn.hutool.json` 共 **30 个非 `package-info` 类**，
覆盖 JSON 解析、序列化、Bean 互转、JSONPath、XML 互转等完整生态。

### 设计原则

1. **功能语义对齐，实现方式 Rust 化**：Java `JSONObject extends JSON` →
   `serde_json::Map<String, Value>` newtype 包装；Java `JSONArray extends JSON` →
   `Vec<Value>` newtype 包装；Java `ObjectMapper` → `serde` 的 `Serialize/Deserialize`
2. **每个 `.rs` 文件只对应一个 Java 对象**：除 `compat.rs`（**单源 dump，违规**）
3. **所有公开类型必须有中文文档注释**：结构体、枚举、trait、方法、字段
4. **模块路径 snake_case**，类型 PascalCase，方法 snake_case
5. **`compat.rs` 必须拆分**：将 1020 行的 JSONObject/JSONArray/JSONConfig/JSONNull
   全部 dump 拆为独立文件

### 与 hutool-json 当前状态的差距

| 维度 | 当前 | 目标 |
|------|------|------|
| Java 非 `package-info` 类 | 30 | — |

> **重要**：`hutool-json/src/compat.rs` 是单源 dump，包含 `JSONConfig` /
> `JSONObject` / `JSONArray` / `JSONNull` / `JsonContainer` / `get_by_path` /
> `put_by_path` / `PathError` 等多个 Java 对象（**9 个违规 crate 之一**），必须
> 拆分为独立 `.rs` 文件。

### S6 — 错误体系（已完成）

```rust
#[derive(Debug, thiserror::Error)]
#[non_exhaustive]
pub enum JsonError {
    #[error("JSON operation failed: {0}")]
    Serde(#[from] serde_json::Error),
    #[error("expected a JSON {expected}, found {actual}")]
    UnexpectedType { expected: &'static str, actual: &'static str },
    #[error(transparent)]
    Path(#[from] PathError),
    #[error("JSON resource limit exceeded: {0}")]
    Limit(&'static str),
    #[error("JSON syntax error: {0}")]
    Syntax(String),
    #[error("JSON I/O failed: {0}")]
    Io(#[from] std::io::Error),
    #[error("JSON input is not UTF-8: {0}")]
    Utf8(#[from] std::string::FromUtf8Error),
    #[error("JSON mapping failed: {0}")]
    Mapping(&'static str),
}
```

覆盖 Java `JSONException` 全部场景 + Rust 特有 I/O 错误。

#[derive(Debug, Clone, PartialEq, Default)]
pub struct JSONObject(pub Map<String, Value>);

impl JSONObject {
    /// 获取键值
    pub fn get<K: AsRef<str>>(&self, key: K) -> Option<&Value> { /* ... */ }
    /// 设置键值
    pub fn put<K: Into<String>>(&mut self, key: K, value: Value) -> Option<Value> { /* ... */ }
}

impl std::ops::Deref for JSONObject {
    type Target = Map<String, Value>;
    fn deref(&self) -> &Self::Target { &self.0 }
}

## 七、风险评估

| 风险 | 影响 | 对策 |
|------|------|------|
| `compat.rs` 1020 行 dump | 违反一文件一对象 | S4 拆分 |

| 浮点数精度 | `f64` 与 Java `double` 差异 | `arbitrary_precision` 开关 |
| 整数边界 | `i64` 溢出 | `write_long_as_string` 配置 |
