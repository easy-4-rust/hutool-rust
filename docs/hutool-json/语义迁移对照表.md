# hutool-json → hutool-json 功能语义迁移对照表

> 基线：Hutool **5.8.x**（`hutool-json` 模块），已覆盖 JSON 解析、序列化、Bean
> 互转、JSONPath、XML 互转、时间类型序列化等场景。
>
> 迁移原则：**功能语义对齐，实现方式 Rust 化**。
> Java 的 Jackson / Fastjson / Hutool JSON 分别映射为：`serde` / `serde_json` /
> 自有 `JSONObject` / `JSONArray` newtype 包装。

## 跨切语义映射

| Java / JVM 概念 | Rust 实现 | 备注 |
|---|---|---|
| Jackson `ObjectMapper` | `serde` + `serde_json` | 序列化 / 反序列化 |
| Fastjson `JSONObject` | `serde_json::Map<String, Value>` newtype | 保持 Map 接口 |
| Fastjson `JSONArray` | `Vec<Value>` newtype | 保持 List 接口 |
| Fastjson `JSONNull` | `serde_json::Value::Null` | 特殊值 |
| `JSONConfig` | `JSONConfig` struct | 解析/序列化开关 |
| `JSONTokener` | `serde_json::Deserializer::from_str` | 流式 tokenizer |
| `JSONPath` | `get_by_path` / `put_by_path` | 点分路径 |
| `XML` ↔ `JSON` | `xml/` 子包 | XML 互转 |
| Jackson `JsonNode` | `serde_json::Value` | 树形结构 |
| `java.time.format.DateTimeFormatter` | `chrono` / `time` | 时间格式 |
| JAXB `XmlElement` | `quick-xml` | XML 解析 |
