## 二、Java 有但 Rust 没有的 4 个类

| Java | 优先级 | 说明 |
|---|---|---|
| `OpensslKeyUtil` | P1 | OpenSSL 密钥工具（推断） |
| `ECKeyUtil` | P1 | EC 密钥工具（推断） |
| `GlobalBouncyCastleProvider` | P1 | 全局 BC Provider（Java 静态初始化） |
| `SmUtil`（顶级聚合类） | P2 | 拆分到 `sm2_util/` + `hutool_facade/sm4.rs` + `hutool_facade/sm3_util.rs` |

### 拆分说明

- `SmUtil` 是国密算法的聚合门面，Rust 端拆分为 3 个独立模块（`sm2_util/` +
  `sm3_util.rs` + `sm4.rs`），不视为缺失
- `OpensslKeyUtil` / `ECKeyUtil` / `GlobalBouncyCastleProvider` 推断为 hutool-crypto
  子包，需确认 Java 端是否存在

## 四、业务逻辑一致性检查

### ✅ 完全一致的逻辑

- AES-256-GCM 加解密
- AES-CBC + PKCS7 填充
- SM2/SM3/SM4 国密算法
- RSA 签名验签（PKCS#1 v1.5 / PSS）
- HMAC-SHA256 / HMAC-MD5
- MD5 / SHA-256 / SHA-512 摘要
- PEM 解析 PKCS#8 / PKCS#1 / SEC1
- HOTP / TOTP 标准实现
- Argon2id / BCrypt 密码哈希
- ECIES 椭圆曲线加密
- FPE (FF1) 格式保留加密

### ⚠️ 部分一致的逻辑

- 加密模式枚举：Java 用 `CipherMode` / `Mode`，Rust 统一在 `aes_modes.rs`
- 密钥规格：Java 用 `SecretKeySpec`，Rust 用 `KeySpecBytes` + `secrecy::Secret`
- PEM 编码：Java 用 `bcpkix`，Rust 用 `x509-parser` + `pem`
- 随机数：Java 用 `SecureRandom`，Rust 用 `OsRng`
- ASN.1：Java 用 BC ASN.1，Rust 用 `der` / `x509-parser`

### ❌ 未实现的逻辑

- `OpensslKeyUtil`（OpenSSL 格式密钥转换）
- `ECKeyUtil`（EC 密钥工具）
- `GlobalBouncyCastleProvider`（Java 静态初始化语义）
- BouncyCastle 后量子算法（PQC）
