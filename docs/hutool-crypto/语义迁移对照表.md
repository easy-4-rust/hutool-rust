# hutool-crypto → hutool-crypto 功能语义迁移对照表

> 基线：Hutool **5.8.x**（`hutool-crypto` 模块），已覆盖对称加密、非对称加密、
> 国密 SM2/SM3/SM4、消息摘要、HMAC、签名验签、PEM/X.509、OTP 等场景。
>
> 迁移原则：**功能语义对齐，实现方式 Rust 化**。
> Java 的 BouncyCastle / `java.security` / `javax.crypto` 分别映射为：
> RustCrypto / `ring` / 各算法 crate。

## 跨切语义映射

| Java / JVM 概念 | Rust 实现 | 备注 |
|---|---|---|
| BouncyCastle `BC` Provider | RustCrypto | 纯 Rust |
| `java.security.MessageDigest` | `digest` trait | SHA-256 / MD5 / SM3 |
| `javax.crypto.Cipher` | 各算法独立封装 | AES / DES / SM4 |
| `javax.crypto.spec.SecretKeySpec` | `KeySpecBytes` | 密钥规格 |
| `java.security.KeyPair` | `RsaPrivateKey` / `RsaPublicKey` | RSA 密钥对 |
| `java.security.Signature` | `Signer` trait | RSA-SHA256 / SM3-SM2 |
| `org.bouncycastle.asn1.*` | `der` / `x509-parser` | ASN.1 解析 |
| `org.bouncycastle.jce.provider.*` | `rcgen` | X.509 证书生成 |
| PEM `PemReader` | `x509-parser` / `pem` crate | PEM 解析 |
| `org.bouncycastle.crypto.engines.SM2Engine` | `libsm` / `sm` crate | 国密 |
| `javax.crypto.Mac` | `hmac` crate | HMAC |
