## 命名与组织规则

1. 目录、文件名一律 `snake_case`；类型 `PascalCase`；方法 `snake_case`
2. **每个 .rs 文件只对应一个 Java 对象**；接口去 Java 匈牙利前缀
3. `mod.rs` 只做模块声明与 re-export，**禁止定义任何类型/逻辑**
4. Java 多层嵌套包只要求**最后一层目录**完全对齐
5. 每个文件头部必须有中文 doc 注释：说明对应 Java 类的全限定名、核心职责
6. 方法级中文注释从 Java 源码同步翻译

## 四、Rust 特有（🆕 3 个，无 Java 对偶）

| Rust 文件 | 语义 | 替代方案 |
|-----------|------|----------|
| `machine_word.rs` | 位宽枚举 `Bits32` / `Bits64` | Java 用 `int[]` / `long[]` 区分 |
| （无） | `BloomFilter<T>` 泛型封装 | Java `BloomFilter` 仅支持 String |
| （无） | `BloomFilterError` 错误枚举 | Java 用 `IllegalArgumentException` |

> 注：`BloomFilter<T>` 与 Java `BloomFilter` 名字相同但语义不同——前者是基于
> `bloomfilter` crate 的**生产级泛型**布隆过滤器，后者是基于 `BitMap` + 单一哈希的
> **字符串**布隆过滤器。命名对齐需要谨慎。
