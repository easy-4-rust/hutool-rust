# hutool-core → hutool-rust 功能语义迁移对照表

基线：Hutool **5.8.x**（`hutool-core`，含 `cn.hutool.core` 全部 30+ 子包）。

迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 的反射、字节码操作、动态代理、ClassLoader 分别映射为：trait 对象、
编译期宏、trait object 装箱、模块路径。

## 状态图例

- ✅ 已迁移并有测试
- 🔀 合并到其他文件
- ⬜ 待迁移（路线图占位）
- 🔶 语义等价但形态不同
- 🚫 不迁移
- 🆕 Rust 特有
