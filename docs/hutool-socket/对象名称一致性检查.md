## 三、Rust 特有（🆕 6 个，无 Java 对偶）

| Rust 文件 | 语义 | 替代方案 |
|-----------|------|----------|
| `lib.rs::SocketError` | 套接字错误枚举（Io/ConnectTimeout/FrameTooLarge） | Java 用 `SocketException` / `IOException` |
| `lib.rs::TcpConfig` | TCP 连接策略 | Java 用 `SocketConfig` |
| `lib.rs::connect_tcp` | 异步 TCP 连接封装 | Java 用 `AsynchronousSocketChannel.connect` |
| `lib.rs::bind_udp` | 异步 UDP 绑定 | Java 用 `DatagramChannel.bind` |
| `lib.rs::read_frame` | 定界符帧读取（带字节限制） | Java 用 `BufferedReader.readLine` |
| `lib.rs::write_frame` | 完整写入 + flush | Java 用 `OutputStream.write + flush` |

## 四、命名风格检查

| 检查项 | Java | Rust | 结论 |
|--------|------|------|------|
| 类型命名 | `PascalCase` | `PascalCase` | ✅ 一致 |
| 方法命名 | `camelCase` | `snake_case` | ✅ 符合 Rust 惯例 |
| 字段命名 | `camelCase` | `snake_case` | ✅ 符合 Rust 惯例 |
| 常量命名 | `UPPER_SNAKE_CASE` | `UPPER_SNAKE_CASE` | ✅ 一致 |
| 文件名 | `PascalCase.java` | `snake_case.rs` | ✅ 符合 Rust 惯例 |
| 目录名 | 小写单词 | `snake_case` | ✅ 一致 |
| 异常后缀 | `*Exception` | `*Exception` | ✅ 一致（保留 `SocketRuntimeException`） |
| 工具后缀 | `*Util` | `*Util` | ✅ 一致（`SocketUtil` / `ChannelUtil` / `NioUtil`） |
| 接口前缀 | 无 | 无 | ✅ 一致（`AioAcceptHandler` / `NioAcceptHandler`） |
| 处理器后缀 | `*Handler` | `*Handler` | ✅ 一致（`AioAcceptHandler` / `ReadHandler` / `ChannelHandler`） |
| 客户端后缀 | `*Client` | `*Client` | ✅ 一致（`AioClient` / `NioClient`） |
| 服务器后缀 | `*Server` | `*Server` | ✅ 一致（`AioServer` / `NioServer`） |
| 会话后缀 | `*Session` | `*Session` | ✅ 一致（`AioSession`） |
| 编码器后缀 | `*Encoder` / `*Decoder` | `*Encoder` / `*Decoder` | ✅ 一致（`MsgDecoder` / `MsgEncoder`） |
| 工厂后缀 | — | — | ➖ 未出现 |
| 抽象前缀 | `Abstract*` | — | ➖ Hutool 此模块未用 |

> 注：hutool-socket 是 hutool-rust 中**保留 Exception 后缀**的少数 crate 之一（而非 Rust
> 惯例的 Error），是因为对外 API 形态与 Hutool Java 端严格对齐，便于业务代码迁移。
> Rust 特有层引入 `SocketError`，体现 Rust 错误风格。
