# hutool-socket 对象级对照表（验收清单）

> 检查时间：2026-07-27
> 基线：Hutool 5.8.x `cn.hutool.socket.*`，20 个非 `package-info` Java 类
> hutool-socket crate：2 个 `.rs` 文件（`lib.rs` + `compat.rs`）
> 规则：每个 Java 类对应一个 Rust `.rs` 文件（`PascalCase` ↔ `snake_case`）

> **重要警告**：当前 `src/compat.rs` 1308 行，**集中 20 个 Java 类**，是 hutool-rust
> **9 个 `compat.rs` 单源 dump 违规 crate 之一**。本表给出 S1 拆分目标。

> **目标结构（按 `cn.hutool.socket` + `cn.hutool.socket.{aio,nio,protocol}` 子包 1:1 对齐）**：
> - 删除 `src/compat.rs`
> - 顶级 4 类平铺：`src/{socket_util.rs, channel_util.rs, socket_config.rs, socket_runtime_exception.rs}.rs`
> - aio 子包 8 类：`src/aio/{aio_client.rs, aio_server.rs, aio_session.rs, aio_util.rs, simple_io_action.rs, accept_handler.rs, read_handler.rs}.rs`
> - nio 子包 6 类：`src/nio/{nio_client.rs, nio_server.rs, nio_util.rs, channel_handler.rs, nio_accept_handler.rs, operation.rs}.rs`
> - protocol 子包 3 类：`src/protocol/{protocol.rs, msg_decoder.rs, msg_encoder.rs}.rs`
>
> **禁止**保留 `compat.rs` / `compat/` 集中定义桶——按 Java 子包 1:1 直接对齐。

本文档与 `语义迁移对照表.md` 互补：语义表回答"功能有没有"，本表回答"**每个 Java 对象
落在哪个 Rust 文件**"，是结构拆分与补缺的验收清单。

## 命名与组织规则

1. 目录、文件名一律 `snake_case`；类型 `PascalCase`；方法 `snake_case`
2. **每个 .rs 文件只对应一个 Java 对象**；接口去 Java 匈牙利前缀
3. `mod.rs` 只做模块声明与 re-export，**禁止定义任何类型/逻辑**
4. Java 多层嵌套包只要求**最后一层目录**完全对齐
5. 每个文件头部必须有中文 doc 注释：说明对应 Java 类的全限定名、核心职责
6. 方法级中文注释从 Java 源码同步翻译
