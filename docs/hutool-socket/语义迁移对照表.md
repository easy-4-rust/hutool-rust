# hutool-socket 功能语义迁移对照表

> 检查时间：2026-07-27
> 基线：Hutool 5.8.x `cn.hutool.socket.*`
> hutool-socket crate：2 个 `.rs` 文件（`lib.rs` + `compat.rs`）

迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 的 `java.nio` / `java.nio.channels` / `io.netty` 分别映射为：`tokio::io` /
`tokio::net` / `tokio::sync` + `tokio::task`。
Java 反射 / `Selector.select` 映射为：`tokio::select!` + 多 `JoinSet`。

状态图例：✅ 已迁移并有测试 / 🔀 语义已迁移但合并 / ⬜ 未迁移 / 🚫 不迁移 / 🆕 Rust 特有

## 五、Rust 特有（🆕 6 个，无 Java 对偶）

### 5.1 `SocketError` 错误枚举

| 变体 | 触发条件 |
|------|----------|
| `Io(io::Error)` | 操作系统 I/O 失败 |
| `ConnectTimeout` | 连接尝试超过 deadline |
| `FrameTooLarge { limit, actual }` | 入站帧超过配置限制 |

### 5.2 `TcpConfig` TCP 连接策略

| 字段 | 类型 | 默认值 |
|------|------|-------|
| `connect_timeout` | `Duration` | `Duration::from_secs(10)` |
| `no_delay` | `bool` | `true` |

### 5.3 异步函数

| 函数 | 签名 | 语义 |
|------|------|------|
| `connect_tcp` | `async fn (addr, TcpConfig) -> Result<TcpStream, SocketError>` | 带超时和 nodelay 的连接 |
| `bind_udp` | `async fn (addr) -> Result<UdpSocket, SocketError>` | 异步 UDP 绑定 |
| `read_frame` | `async fn (R, u8, usize) -> Result<Vec<u8>, SocketError>` | 定界符定界帧读取（带字节限制） |
| `write_frame` | `async fn (W, &[u8]) -> Result<(), SocketError>` | 完整写入 + flush |

### 5.4 单元测试（`lib.rs::tests`）

| 测试 | 语义 |
|------|------|
| `framed_io_is_bounded` | 定界符帧 + 长度限制 + I/O 错误 |
| `tcp_udp_and_default_policy_use_real_loopback_sockets` | TCP/UDP 真回环 + 默认策略 |
