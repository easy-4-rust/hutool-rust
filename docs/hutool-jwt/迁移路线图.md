# hutool-jwt 全量迁移路线图

> 版本：v1.0（2026-07-27）｜基线：Hutool **5.8.x**（`cn.hutool.jwt.*`）
> 仓库：easy-4-rust/hutool-rust @ dev ｜ 本文档随代码同步维护，每阶段完成时更新

## 一、总目标

以 Hutool 5.8.x 的 `hutool-jwt` 模块（`cn.hutool.jwt.*`，15 个非 `package-info` Java
类）为蓝本，实现功能语义完全对齐的 `hutool-jwt` crate。`hutool-jwt` 提供 JSON Web
Token（JWT）的完整封装：算法选择、签名、验证、Claims 构造、注册声明常量、异常体系。

### 设计原则

1. **功能语义对齐，实现方式 Rust 化**：Java `JJWT` / `nimbus-jose-jwt` →
   `jsonwebtoken` crate；Java `BouncyCastle` → `rsa` / `p256` RustCrypto
2. **每个 .rs 文件只对应一个 Java 对象**：对齐 hutool-rust 一文件一对象规范
3. **公开类型必须有中文文档注释**：结构体、枚举、trait、方法、字段
4. **模块路径 snake_case**，类型 PascalCase，方法 snake_case
5. **保持 Hutool API 形态**：对外暴露 `JWT` / `JWTUtil` / `Claims` / `JWTException`
   等命名，便于 Java 业务代码迁移

### 与 hutool-jwt 当前状态的差距

| 维度 | 当前 | 目标 |
|------|------|------|
| Java 类数 | 15 | 15 |
| Rust 文件数 | 2（`lib.rs` + `compat.rs`） | 15+ |
| `compat.rs` 行数 | 1694 ❌ | 200（仅 mod 声明） |
| `compat.rs` 单源 dump 违规 | 是 | 否 |
| Cargo `jsonwebtoken` 依赖 | ✅ 0.6.x | ✅ |
| HMAC 签名（HS256/384/512） | ✅ | ✅ |
| RSA 签名（RS256/384/512） | ✅ | ✅ |
| ECDSA 签名（ES256/384/512） | ✅ | ✅ |
| None 算法 | ✅ | ✅ |
| 单元测试 | ✅ `lib.rs::tests` | ✅ + 拆分后每文件 1+ |

> **警告**：当前 `src/compat.rs` 1694 行，单一文件集中 14 个 Java 类（JWT/JWTUtil/
> Claims/JWTHeader/JWTPayload/RegisteredPayload/JWTException/JWTSigner/AlgorithmUtil/
> JWTSignerUtil/HMacJWTSigner/AsymmetricJWTSigner/EllipticCurveJWTSigner/NoneJWTSigner），
> **严重违反 AGENTS.md "单文件 ≤ 200 行" 红线**。这是 hutool-rust **9 个 `compat.rs`
> 单源 dump 违规 crate 之一**，需要 S1 重点拆分。

## 六、风险与依赖

| 风险 | 影响 | 缓解 |
|------|------|------|
| `compat.rs` 1694 行单源 dump | 严重违反 AGENTS.md 红线 | S1 拆分 14 个文件 |
| `JWT` 类的可变 `Signer` 引用 | 拆分时需保证泛型签名兼容 | 保留 `Arc<dyn JWTSigner>` |
| `JWTValidator` 时区/时钟偏移 | Rust 端用 `Validation.leeway` | 已实现 |
| `Claims` JSON 字段顺序 | Java Hutool 不保证，Rust 同 | 透传 `serde_json::Value` |
| `JJWT` 的 `KeyLocator` 接口 | Rust 端无对偶 | 暂不迁移 |
| `nimbus-jose-jwt` 的 JWE 加密 | Hutool 不支持 | 不迁移 |
| `RSA` 私钥 PKCS#1 vs PKCS#8 编码 | Rust `rsa` 区分 | 在 `AsymmetricJWTSigner` 内做转换 |
| `ES256/384/512` 曲线选择 | Rust `p256` 限定 P-256 | 文档化 |
