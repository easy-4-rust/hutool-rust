# hutool-setting → hutool-rust 对象级对照表（验收清单）

基线：hutool **5.8.x**（hutool-setting），覆盖 **15+ 个 Java 类**。
本文档与 `语义迁移对照表.md` 互补：语义表回答"功能有没有"，
本表回答"**每个 Java 对象落在哪个 Rust 文件**"，是结构拆分与补缺的验收清单。

## 目标工程结构（Cargo workspace）

```
hutool-rust/
├── Cargo.toml                        # workspace 根
└── crates/
    └── hutool-setting/
        ├── Cargo.toml                # crate 元数据
        └── src/
            ├── lib.rs                # crate 门面 + 顶层类型（SettingError / SettingsLoader / FileSource）
            │
            ├── setting/              # 顶层 Setting
            │   ├── mod.rs
            │   ├── setting.rs        # Setting
            │   └── auto_load_handle.rs # AutoLoadHandle
            │
            ├── setting_util.rs       # SettingUtil
            ├── setting_loader.rs     # SettingLoader
            │
            ├── props.rs              # Props
            ├── props_util.rs         # PropsUtil
            │
            ├── profile.rs            # Profile
            ├── global_profile.rs     # GlobalProfile
            │
            ├── grouped_map.rs        # GroupedMap
            ├── grouped_set.rs        # GroupedSet
            │
            └── yaml.rs               # YamlUtil
```

## 命名与组织规则

1. 目录、文件名一律 `snake_case`；类型 `PascalCase`；方法 `snake_case`
2. **每个 .rs 文件只对应一个 Java 对象**；接口去 Java 匈牙利前缀
3. `mod.rs` 只做模块声明与 re-export，**禁止定义任何类型/逻辑**
4. Java 多层嵌套包只要求**最后一层目录**完全对齐
5. 每个文件头部必须有中文 doc 注释：说明对应 Java 类的全限定名、核心职责
6. 方法级中文注释从 Java 源码同步翻译

## 七、不迁移 / 合并 / 拆分说明

| Java 实体 | 处理方式 | 理由 |
|----------|----------|------|
| `AbsSetting` | 🔀 合并到 `Setting` | Java 抽象基类只有一个直接子类 |
| `SettingRuntimeException` | 🔶 改名为 `SettingError` | 改为枚举而非异常类 |
| `Setting.settingLoader` 内部类 | 🔀 拆为顶层 `setting_loader.rs` | 更符合 Rust 顶层模块习惯 |
| `Setting.groupedMap` 字段 | 🔀 拆为顶层 `grouped_map.rs` | 同上 |
| `Setting.autoLoad` 行为 | 🆕 拆为 `auto_load_handle.rs` | Rust 借用模式需要 handle 类型 |
| `cn.hutool.log.StaticLog` | 🚫 不迁移 | 由 `log` / `tracing` crate 替代 |

## 八、类型风格映射

| Java 类型 | Rust 类型 |
|----------|----------|
| `Setting extends Map<String, String>` | `Setting` struct + `Arc<RwLock<GroupedMap>>` 字段 |
| `GroupedMap extends LinkedHashMap<...>` | `GroupedMap` struct + `IndexMap<...>` 字段 |
| `Props extends Properties extends Hashtable` | `Props` struct + `IndexMap<String, String>` 字段 |
| `Charset charset` | `&'static Encoding` |
| `Resource resource` | `Option<PathBuf>` |
| `WatchMonitor` | `notify::RecommendedWatcher`（在 `AutoLoadHandle` 内） |
| `static Map<String, Setting> SETTING_MAP` | `SettingsLoader` + `Config` 实例 |
| `SettingRuntimeException` | `SettingError` enum + `SettingRuntimeException` 类型别名 |
