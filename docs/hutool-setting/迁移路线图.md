# hutool-setting 全量迁移路线图

> 版本：v1.0（2026-07-27）｜基线：hutool **5.8.x**（hutool-setting）
> 仓库：easy-4-rust/hutool-rust @ dev ｜ 本文档随代码同步维护，每阶段完成时更新

## 一、总目标

以 Hutool 5.8.x 的 `hutool-setting` 模块为蓝本，实现**功能语义对齐、Rust 化
实现**的 `hutool-setting` crate，覆盖：
- 分组键值对配置（Setting / GroupedMap / GroupedSet）
- Java 属性文件解析（Props / PropsUtil）
- 多环境 Profile 切换（Profile / GlobalProfile）
- YAML 读写（YamlUtil）
- 自动热加载（AutoLoad / Watcher）
- 静态工具（SettingUtil）

### 设计原则

1. **功能语义对齐，实现方式 Rust 化**：Java `Properties extends Hashtable` →
   Rust `IndexMap<String, String>`；Java `LinkedHashMap` 保留顺序；
   Java `WatchMonitor`（JDK NIO WatchService）→ Rust `notify` crate
2. **每个 .rs 文件只对应一个 Java 对象**：对齐 liteflow-rust 的一文件一对象规范
3. **公开类型必须有中文文档注释**：结构体、枚举、trait、方法、字段
4. **模块路径 snake_case**，类型 PascalCase，方法 snake_case
5. **错误体系统一为 `thiserror::Error`**，由 `SettingError` 顶层枚举聚合
6. **配置加载复用 `config` crate**：YAML / JSON / TOML / INI / env vars 统一入口

## 三、阶段详细计划

### S1 — 顶层门面（已完成）

**范围**：`cn.hutool.setting` 根包 3 个核心类型

| Rust 文件 | Java 类 | 状态 |
|-----------|---------|------|
| `setting/setting.rs` | `Setting` | ✅ |
| `setting/mod.rs` | （子模块声明） | ✅ |
| `setting/auto_load_handle.rs` | （Setting 内部 AutoLoad 句柄） | ✅ |
| `setting_util.rs` | `SettingUtil` | ✅ |
| `setting_loader.rs` | `SettingLoader` | ✅ |

**关键差异**：

- Java `Setting extends AbsSetting implements Map<String, String>` →
  Rust `Setting` 组合 `Arc<RwLock<GroupedMap>>` 而非 `impl Map`
- Java `static Setting create()` 工厂 → Rust `Setting::new()` / `Setting::create()`
- Java `Charset` → Rust `&'static Encoding`（`encoding_rs`）
- Java `Resource` 抽象（classpath / file / url）→ Rust `&Path` + 加载策略
- 变量替换（`${var}`）→ Rust 字符串解析
- 自动重载：`WatchMonitor`（Java NIO）→ `notify::RecommendedWatcher`

**验收**：单测覆盖 `Setting::new()` / `set` / `get` / `get_str` / `get_int`。

## 五、不迁移的内容

| Java 实体 | 不迁移原因 |
|-----------|----------|
| `SettingRuntimeException` | 改为 `SettingError` 顶层枚举（`thiserror::Error`） |
| Java 反射相关 | 不需要 |
| `cn.hutool.log.StaticLog` | 由应用层 `log` / `tracing` 替代 |
| SnakeYAML 自定义 Tag | 改用 `serde` derive |

## 六、风险与注意事项

1. **编码**：Java 默认 `ISO-8859-1` / 显式 `UTF-8`；Rust 默认 `WINDOWS-1252` 兼容
   ISO-8859-1（Hutool 对齐），用户可显式指定 `UTF_8`
2. **变量替换**：`${var}` 解析顺序：先本组，再全局；Java 同理
3. **Profile 路径**：Rust 用相对路径而非 classpath，应用层自行 setup working dir
4. **YAML 库选择**：`serde_yaml_ng` 替代 `serde_yaml`（后者已弃用）
5. **自动加载依赖**：`notify` crate 在 Windows 上需要 `ReadDirectoryChangesW`，
   macOS 上是 FSEvents，Linux 上是 inotify
