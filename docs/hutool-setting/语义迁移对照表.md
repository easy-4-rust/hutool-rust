# hutool-setting → hutool-rust 功能语义迁移对照表

基线：hutool **5.8.x**（hutool-setting）。迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 的 `Properties` / `LinkedHashMap` / `WatchMonitor` / `SnakeYAML` 分别映射为
`IndexMap` / `IndexMap` / `notify` crate / `serde_yaml_ng`。

状态图例：✅ 已迁移并有测试 / 🔶 语义等价但形态不同 / ⬜ 未迁移（路线图）/ 🚫 不迁移

## 一、跨切语义映射

| Java 概念 | Rust 替代 | 适用位置 | 状态 |
|-----------|----------|----------|------|
| `Properties` | `IndexMap<String, String>` | Props | ✅ |
| `LinkedHashMap` | `IndexMap` | GroupedMap / GroupedSet | ✅ |
| `Charset` | `&'static Encoding`（encoding_rs） | 全局 | ✅ |
| `Resource` | `&Path` | Setting / Props | ✅ |
| `WatchMonitor` | `notify` crate | Setting autoLoad | ✅ |
| `SnakeYAML` | `serde_yaml_ng` | YamlUtil | ✅ |
| Hutool `Setting` (cn.hutool.setting) | config crate | 通用配置 | ✅ |
| Hutool `Log` | `log` / `tracing` crate | 日志 | ✅ |
| `SafeConcurrentHashMap` | `RwLock<HashMap<>>` | GlobalProfile 缓存 | ✅ |
| `ReentrantReadWriteLock` | `RwLock<T>` | GroupedMap | ✅ |
