## 四、命名规范说明

1. **PascalCase ↔ snake_case**：所有 Java 类名转 Rust 文件名时统一转 snake_case
2. **Java 内部类拆为顶层**：
   - `Setting` 内部 `settingLoader` 字段 → 顶层 `setting_loader.rs`
   - `Setting` 内部 `groupedMap` 字段类型 → 顶层 `grouped_map.rs`
   - `Setting` 内部 `autoLoad` 行为 → 顶层 `auto_load_handle.rs`（RAII handle）
3. **`Setting` 子目录**：把 `Setting` 拆为 `setting/mod.rs` + `setting/setting.rs` +
   `setting/auto_load_handle.rs`，更清晰地表达"Setting 模块"概念
4. **错误类型命名**：Java `XxxException` → Rust `XxxError` enum
5. **类型别名 `SettingRuntimeException`**：保留 Java 风格别名，便于 Hutool 用户
   切到 Rust 时无感知

## 八、与 hutool-db 的关联

- `hutool-db::GlobalDbConfig` 依赖 `hutool-setting::Setting` 读取 `db.setting`
- Rust 端：`hutool-db::ds::DbSetting` 直接桥接 `hutool-setting::Setting`
- `SettingsLoader`（基于 `config` crate）作为通用配置加载入口

## 九、与 hutool-core 的关联

- `hutool-core::io.resource.Resource` → Rust 端使用 `&Path` + 加载策略
- `hutool-core::io.watch.WatchMonitor` → Rust 端使用 `notify::RecommendedWatcher`
- `hutool-core::lang.Assert` → Rust 端通过 `Result<T, SettingError>` 提前返回

- **Rust 特有**：7 个（SettingError / SettingRuntimeException / FileSource /
