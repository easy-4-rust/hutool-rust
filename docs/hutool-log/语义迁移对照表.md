# hutool-log 功能语义迁移对照表

基线：hutool-log **5.8.43+**，覆盖 50+ 个类（顶级 + level + 10 个 dialect）。
本文档回答"功能有没有"，与 `对象级对照表.md` 互补。

迁移原则：**功能语义对齐，实现方式 Rust 化**。Java 反射 SPI + 静态字段
+ 线程 ThreadLocal 全部映射为：`tracing` 生态 + 编译期类型别名 + `OnceLock`。

状态图例：✅ 已迁移并有测试 / 🔀 已合并待拆 / ⬜ 未迁移（路线图）/ 🚫 不迁移 / 🆕 Rust 特有

| Java 抽象 | 语义 | Rust 实现 | 状态 |
|----------|------|----------|------|
| `Level.TRACE` | 最详细 | `LogLevel::Trace` | ✅ |

| `Level.INFO` | 普通 | `LogLevel::Info` | ✅ |
| `Level.WARN` | 警告 | `LogLevel::Warn` | ✅ |
| `Level.ERROR` | 错误 | `LogLevel::Error` | ✅ |

| `Level.toString()` | 大写 | `impl Display` 输出大写 | ✅ |
| `Level` 数值比较 | 5 级排序 | `PartialOrd` 隐式 | ✅ |
