# hutool-log 对象级对照表（验收清单）

基线：hutool-log **5.8.43+**，Java 源共 **50+ 个类**（含顶级 5 个 + level
子包 6 个 + 10 个 dialect × 2-3 个类）。
hutool-log 是 hutool 体系下类数量最多的"薄模块"之一，迁移策略：
**核心抽象 + 10 个 dialect 类型别名**。

## 目标工程结构

```
hutool-log/
├── Cargo.toml                            # crate 根
└── src/
    ├── lib.rs                            # crate 门面 + init/env_filter/Redacted + dialect 类型别名
    │
    └── compat/                           # Hutool 兼容层（✅ 已正确拆分）
        ├── mod.rs                        # 模块声明 + 公共 re-export + format_message + global_slot
        ├── log.rs                        # Log trait
        ├── log_level.rs                  # LogLevel enum
        ├── log_record.rs                 # LogRecord struct
        ├── log_sink.rs                   # LogSink trait
        ├── tracing_sink.rs               # TracingSink（默认实现）
        ├── abstract_log.rs               # AbstractLog struct
        ├── tracing_log.rs                # TracingLog 类型别名
        ├── log_factory.rs                # LogFactory struct
        ├── global_log_factory.rs         # GlobalLogFactory 静态访问
        └── static_log.rs                 # StaticLog 静态门面
```

## 命名与组织规则

1. 目录、文件名一律 snake_case；类型 PascalCase；方法 snake_case
2. **每个 .rs 文件只对应一个 Java 对象**（顶级 / 公共对象）
3. `mod.rs` 只做模块声明与 re-export，**禁止定义任何类型/逻辑**（仅工具函数 `format_message` 与 `global_slot`）
4. Java `dialect.*` 多个类 → Rust `lib.rs::dialect` 下的 `pub type` 别名
5. 每个文件头部必须有中文 doc 注释：说明对应 Java 类的全限定名、核心职责
6. **单源 dump 治理**：当前已正确拆分，无需进一步拆分

## 四、不迁移（Java 生态特有）

| Java 类 | 原因 | Rust 替代 |
|---------|------|----------|
| `cn.hutool.log.LogRecord`（log4j 风格） | 与 `cn.hutool.log.Log` 重复 | 合并到 `Log` trait 的 `log_record` |
| `cn.hutool.log.dialect.slf4j.Slf4jLogFactory.createLog` | 反射 ClassLoader | `TracingLog::new` 统一 |
| `cn.hutool.log.dialect.log4j.Log4jLogFactory` | log4j 1.x 反射 | `tracing-log` 桥接 |
| `cn.hutool.log.dialect.log4j2.Log4j2LogFactory` | log4j 2.x 反射 | `tracing-log4j` 桥接 |
| `cn.hutool.log.dialect.jboss.JbossLogFactory` | JBoss LogManager | 不迁移（容器特定） |
| `cn.hutool.log.dialect.logtube.LogTubeLogFactory` | 阿里 LogTube | 不迁移（阿里云特定） |
| `cn.hutool.log.dialect.tinylog.TinyLogFactory` | tinylog 反射 | 不迁移（小型项目） |
| `META-INF/services/cn.hutool.log.LogFactory` | Java SPI | 不适用 |
