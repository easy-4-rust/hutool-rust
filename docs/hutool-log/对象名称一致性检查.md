## 四、命名差异（重命名记录）

| Java | Rust | 重命名原因 |
|------|------|-----------|
| `cn.hutool.log.level.Level` | `LogLevel` | 避免与 `tracing::Level` 冲突（再别名 `pub mod level::Level`） |
| `cn.hutool.log.StaticLogFactory` | `GlobalLogFactory` | 更明确「进程级全局」语义 |
| `Log.getName()` | `Log::name() -> &str` | Rust 命名 |
| `Log.isTraceEnabled()` | `Log::is_enabled(LogLevel::Trace)` | 单一方法支持 5 级 |
| `LogFactory.getLog(String)` | `LogFactory::get(name)` | 缩短 |
| `LogFactory.getLog(Class<?>)` | `LogFactory::get(name)`（类名转字符串） | 强类型 |
| `LogFactory.createLog(String)` | `LogFactory::create(name)` | 缩短 |
| `LogFactory.getCurrentLogFactory()` | `LogFactory::get_current` | 实例方法 |
| `LogFactory.setCurrentLogFactory(...)` | `LogFactory::set_current(factory)` | 实例方法 |
| `LogFactory.get(String)`（静态） | `LogFactory::get_by_name(name)` | 区分实例/静态 |
| `LogFactory.get()`（静态） | `LogFactory::get_current()` | 区分 |
| `AbstractLog.log`（抽象方法） | `AbstractLog::log_record` | 显式命名 |
| `Log.log(Level, ...)` | `Log::log_fmt(level, ...)` | 显式区分 `log` 与 `log_record` |
| `Log.log(Level, throwable, ...)` | `Log::log_fqcn` | 包含 FQCN + Throwable 统一 |
| `Log.warn(Throwable, ...)` | `Log::error_with_cause` | 统一异常处理 |
| `StaticLog.trace(String, Object...)` | `StaticLog::trace_fmt` | 显式模板 |
| `StaticLog.get()` | `StaticLog::get_default()` | 显式默认 |
| `LogRecord.thrown` | `LogRecord::error: Option<String>` | 简化（`String` 而非 `Throwable`） |
| `LogRecord.threadName` | 不存在 | `tracing::Span` 承担 |
| `dialect.*::LogFactory` | 全部 `= LogFactory` | 类型别名统一 |
| `dialect.*::Log` | 全部 `= TracingLog` | 类型别名统一 |
| `META-INF/services/...` | 不存在 | 编译期类型别名 |
