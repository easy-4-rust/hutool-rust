# hutool-ai 功能语义迁移对照表

基线：hutool-ai **5.8.43+**，覆盖 7 大厂商（OpenAI / DeepSeek / Doubao / Gemini /
Grok / Ollama / Hutool）。本文档回答"功能有没有"，与 `对象级对照表.md` 互补。

迁移原则：**功能语义对齐，实现方式 Rust 化**。Java 反射 + SPI + 阻塞 HTTP
映射为：trait 对象 + 枚举穷举 + 异步 `hutool_http`。

状态图例：✅ 已迁移并有测试 / 🔀 已合并待拆 / ⬜ 未迁移（路线图）/ 🚫 不迁移 / 🆕 Rust 特有

## 六、HTTP 与请求层

| Java 抽象 | 语义 | Rust 实现 | 状态 |
|----------|------|----------|------|
| HTTP POST 请求 | 通用方法 | `Operation` 决定，`POST/GET/DELETE` 分类 | ✅ |
| 鉴权头 `Authorization: Bearer ...` | Bearer | `request.bearer_auth(key)`（非 Gemini/Ollama） | ✅ |
| Gemini 鉴权 `?key=...` query | URL 参数 | `url.query_pairs_mut().append_pair("key", key)` | ✅ |
| Ollama 无鉴权 | 跳过 | `if !matches!(Gemini, Ollama)` | ✅ |
| 端点路径拼接 | `apiUrl + endpoint` | `format!("{root}{endpoint}")` | ✅ |
| SSE 流式 | Java 端 ServerSentEvent | 自实现 `SseDecoder` | ✅ |
| SSE 终止 `[DONE]` | 标准 OpenAI | 解析时跳出 | ✅ |
| 二进制响应 | TTS WAV | `AIResponse::Bytes` | ✅ |
| JSON 响应 | 标准 | `AIResponse::Json(serde_json::Value)` | ✅ |
| 响应大小限制 | 64 MiB | `MAX_MEDIA_BYTES` 常量 | ✅ |
| 流式事件大小限制 | 256 KiB | `MAX_SSE_EVENT_BYTES` | ✅ |
| 请求方法选择 | Java 端通过 ServiceImpl | `match operation` 选择 Method | ✅ |
| 代理支持 | `java.net.Proxy` | `Url` 透传给 reqwest | ✅ |
| 超时设置 | int ms | `Duration` | ✅ |
| 重试机制 | 无内置 | 无（用户层包装） | 🚫 |

## 七、错误体系

| Java 异常 | 语义 | Rust 实现 | 状态 |
|----------|------|----------|------|
| `AIException` | 通用异常 | `ProviderError` | ✅ |
| `IllegalArgumentException`（Unsupported model） | 模型名不识别 | `ProviderError::UnsupportedProvider(String)` | ✅ |
| `IllegalArgumentException`（Service 类型不匹配） | 类型不匹配 | 不需要（Rust 端 trait 强类型） | 🚫 |
| `RuntimeException`（HTTP 错误） | 传输错误 | `ProviderError::Http(HttpError)` | ✅ |
| `JsonProcessingException` | JSON 错误 | `ProviderError::Json(serde_json::Error)` | ✅ |
| 响应超过限制 | 自定义 | `ProviderError::ResponseTooLarge { limit }` | ✅ |
| SSE 事件超过限制 | 自定义 | `ProviderError::StreamEventTooLarge { limit }` | ✅ |
| `EmptyChoices` 业务异常 | 空 choices | `ProviderError::EmptyChoices` | ✅ |
| `StreamingUnsupported` | provider 不支持流 | `ProviderError::StreamingUnsupported` | ✅ |
