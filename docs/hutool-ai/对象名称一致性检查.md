## 四、命名差异（重命名记录）

| Java | Rust | 重命名原因 |
|------|------|-----------|
| `OpenaiConfig` / `OpenaiService` | `OpenAiModel` / `OpenAiCompatibleProvider` | Rust PascalCase 规范 |
| `AIException` | `ProviderError` | `thiserror` 命名风格 |
| `BaseAIService` | `ProviderService` | 反映「按 ModelName 路由」语义 |
| `Models.Openai` | `OpenAiModel` | 顶层 enum，与 `ModelName` 平级 |
| `service_name()` 返回 String | `service_name() -> ModelName` | 强类型 |
| `getServiceName().toLowerCase()` | `ModelName::parse()` | 独立解析逻辑 |
| `Class<T> clazz` | `Arc<dyn AIService>` | trait object |
| `Message.setContent(Object)` | `Operation` 携带 `additional` | 多态内容走 Operation |
